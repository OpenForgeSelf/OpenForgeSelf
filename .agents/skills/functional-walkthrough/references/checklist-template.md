# 走查清单模板

复制到报告 §1，按任务删减增补。**禁止**走完只填失败行。

## A. 环境与服务

| ID | 检查项 | 预期 |
|----|--------|------|
| A01 | API 端口为本版构建 | 9201 监听且无昨日残留进程 |
| A02 | 前端可加载 | 9280 登录后进入目标菜单 |
| A03 | 登录态有效 | 非 401 工作台 |

## B. 元数据与表单

| ID | 检查项 | 预期 |
|----|--------|------|
| B01 | 新增表单字段集 | 与 DEC/REQ 一致（含「不应出现」字段） |
| B02 | 必填星号与前端校验 | 与后端必填一致（Cube：`!nullable`） |
| B03 | 请求体字段 | 无 DEC 声明忽略的字段 |

## C. 主路径与负向

| ID | 检查项 | 预期 |
|----|--------|------|
| C01 | 正向建单/主操作 | code=0，关键字段来自规则/设计 |
| C02+ | 各 AC 负向场景 | 约定 code/message |

## D. 列表、详情、关联配置页

| ID | 检查项 | 预期 |
|----|--------|------|
| D01 | 列表刷新 | 新数据可见 |
| D02 | 详情/时间线 | 异步步骤有记录 |
| D03 | 关联配置 UI | 标签/单选/占位与 DEC 一致 |

## E. 证据

| ID | 检查项 | 预期 |
|----|--------|------|
| E01 | 每 AC 至少一条实证 | JSON 或 UI 可读文案 |
| E02 | 共享库写操作 | 报告明示单号 |

## 样例：REQ-WO-178 / DEC-20261110-01（建单必传规则编号）

| ID | 检查项 | 预期 |
|----|--------|------|
| B01 | PC 新建表单 | 无板块/类型/优先级；有规则编号、标题、发生时间等 |
| B02 | 规则编号必填 | 有红星；空规则编号前端拦截或可接受与后端 2001 一致（以 REQ 为准） |
| B03 | POST 体 | 仅 ruleNo、title、occurTime 等；无 section/orderType/priority |
| C01 | 有效启用规则 | code=0；优先级 P3；板块/类型来自规则 |
| C02 | 空 ruleNo | 2001 必填字段缺失 ruleNo |
| C03 | 不存在规则 | 40401 规则不存在 |
| C04 | 无处理人规则 | 40001 未配置处理人 |
| D01 | 列表首行 | 工单号、板块/类型展示 |
| D02 | 详情抽屉 | 分派时间线、处理人、P3 |
| D03 | 规则编辑 | 标签「板块」；告警来源单选；类型占位不写「生效区域」 |
| D04 | 规则摘要 | 板块/类型中文名，非 `#` 码 |
