## 本轮定稿（炳宏 · 2026-11-04 · 可叫前后端 / AI / 测试）

- [x] **引擎**：MVP 即支持多类型（SQLite / MySQL / PostgreSQL / SQL Server 等现成 XCode provider）；做齐配置页（provider 选择、连接串/表单、测连、驱动缺失提示）。**验收仅实测 SQLite**，其它库可配置可用、文档标「未实测」
- [x] **宿主/其它插件库**（PluginDbs）：系统只读挂出（可浏览、`db_query_readonly`）；**写操作硬拒**。用户自建连接可写（经审批），ConnName 隔离为 `DbAdminU_*`
- [x] **写权限**：默认 AskWrite；无 WHERE 的 UPDATE/DELETE、多语句盲跑、DROP DATABASE **硬拒**；普通 DML/DDL 走 AskWrite；破坏性二次确认
- [x] **密码**：插件库加密字段；GET 掩码；审计 / chat / CT fixture 无明文；后续可迁宿主 vault
- [x] **结果上限**：Agent 回传 ≤1000 行 / ≤256KB（带 `truncated`）；人机 UI 分页
- [x] **Agent 工具**：Must `db_list_connections` / `db_list_tables` / `db_describe_table` / `db_query_readonly` / `db_execute_write`；Should `db_set_permission_mode` / `db_resolve_approval`；**不做** Agent 自建连接；`db_explain` 下里程碑
- [x] **UI**：左「连接 + schema 树」、右「SQL 编辑器 + 结果格」；验收态 S0–S8 + S-R + **新增 S9 多 provider 配置态**
- [x] **非目标**：表设计器、ER 图、多引擎市场；只跑 SQL，不跑 shell
- [x] 查询执行锁定 XCode ORM `DAL`（`DAL.AddConnStr` → `DAL.Create` → `Tables` / `Query` / `Execute`，参数化）
- [x] `ToolNamespace.PrefixByPluginId["db-admin"]="db"` **一开始就登记**

确认完成前不推远程。前端 / 后端 / AI 按 02 / 03 / 04 实现；测试按 06 的 S0–S9 + S-R 出截图证据。
