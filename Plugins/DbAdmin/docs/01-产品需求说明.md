# 01 · 产品需求说明

## 1. 定位

「本地 + Agent-first 的轻量数据库管理台」：人在页面里连库、看表、跑 SQL；Agent 通过 `db_*` 工具在**可审批、可审计**的前提下查库与改库。对标 DBeaver / DataGrip 的**常用子集**，不是全量克隆。

对外一句话：**「可审批的 SQL 工作台」**。

## 2. 目标用户与场景

| 场景 | 说明 |
|------|------|
| 看宿主 / 插件数据 | 只读浏览 ForgeSelf 自身与各插件的 SQLite 库，排查数据 |
| 管理自建库 | 用户新建连接（SQLite 文件或 MySQL/PG/SQL Server/Oracle），跑查询与 DML/DDL |
| Agent 协助 | Agent 列连接、看表结构、只读查询；写操作挂起等人批 |

## 3. 范围（MVP · 定稿）

1. **连接管理**：新建/编辑/删除（仅删配置，**绝不删库文件**）/ 测连；provider 选择 + 表单或原始连接串；驱动缺失明确提示  
2. **多引擎**：SQLite / MySQL / PostgreSQL / SQL Server / Oracle 等 XCode 现成 provider。**仅 SQLite 实测验收**，其它标「未实测」  
3. **系统只读连接**：宿主库与 `XCodeConfig.PluginDbs` 所列插件库自动挂出，只读；任何写入硬拒  
4. **Schema 浏览**：库 → 表/视图 → 列（类型、可空、主键、索引）  
5. **SQL 编辑器 + 结果格**：执行、分页、耗时/影响行数、错误可见；历史记录可重跑  
6. **写闸门**：默认 AskWrite；硬拒清单见 04；破坏性二次确认  
7. **审计**：所有执行（含拒绝 / 审批）落审计，参数与密码脱敏  
8. **Agent 工具**：Must 5 个 + Should 2 个（见 04§4）  
9. **刷新恢复**：恢复连接列表 + 当前连接 + 编辑器草稿（不含密码）

## 4. 非目标（定稿）

- 表设计器、ER 图、数据导入导出向导、多引擎市场 / 驱动在线下载  
- 执行 shell / 外部命令（只跑 SQL）  
- Agent 自建 / 修改连接  
- `db_explain`（下里程碑）  
- 宿主库写入（任何模式下都不行）

## 5. 约束

- 执行链路统一用 XCode `DAL`，参数化；不自行拼接用户值  
- 插件代码**不得自动删除**任何数据库文件或数据目录  
- 宿主当前仅随附 SQLite provider；其它 provider 需额外 NuGet（见 05）
