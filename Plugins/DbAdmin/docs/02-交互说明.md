# 02 · 交互说明（给设计师）

## 1. 布局

```
┌ Header：数据库管理 [v版本徽标] · 副标题「可审批的 SQL 工作台」· 权限徽章 · 审计 ┐
│ Banner：错误 / 401 / 驱动缺失（按需）                                         │
├──────────── 左栏 ────────────┬──────────────── 右区 ─────────────────────────┤
│ [+ 新建连接]                 │ 连接: <名称>  provider 标签  [只读] 徽标       │
│ ▸ 系统（只读）               │ ┌ SQL 编辑器（多行，Ctrl+Enter 执行）───────┐ │
│   ▸ ForgeSelf  🔒            │ └────────────────────────────────────────────┘ │
│   ▸ FileTools  🔒            │ [执行] [历史]           耗时 / 影响行数        │
│ ▸ 我的连接                   │ ┌ 结果格（分页、列头类型提示）──────────────┐ │
│   ▸ demo.db                  │ └────────────────────────────────────────────┘ │
│     ▸ 表 users               │ 分页：‹ 1 2 3 › 每页 50/100/500                │
│       · id INTEGER PK        │                                                │
└──────────────────────────────┴────────────────────────────────────────────────┘
浮层（互斥）：连接表单 → 审批 → 破坏性二次确认 → 审计抽屉
```

## 2. 连接表单（多 provider · S1 / S9）

- provider 下拉：SQLite / MySQL / PostgreSQL / SQL Server（未随附驱动的项带「需驱动」灰标，仍可选）  
- 模式切换：**表单**（host/port/database/user/password；SQLite 为文件路径）↔ **连接串**（原样输入）  
- 密码框遮罩；编辑已有连接时显示 `****`，留空 = 不改  
- [测试连接]：成功（绿，显示服务器版本）/ 失败（红，原因，已脱敏）/ 驱动缺失（黄，指明需安装的 `XCode.*` 包）  
- 非 SQLite 表单旁固定提示「未实测」  
- 保存即落盘；失败留窗显示原因

## 3. 执行与审批

1. 只读（SELECT / WITH）直接执行，结果分页  
2. 写语句（AskWrite 下）→ 审批弹窗：展示语句、类型、目标连接、预估风险 → 批准 / 拒绝  
3. 破坏性（DROP TABLE / TRUNCATE / ALTER … DROP 等）→ 审批后再二次确认（`ElMessageBox.confirm`）  
4. 硬拒（无 WHERE 的 UPDATE/DELETE、多语句、DROP DATABASE、系统只读连接上的任何写）→ 直接红条拒绝，不弹审批  
5. Agent 发起的写同样进审批队列，弹窗标注「来自 Agent」

## 4. 五态

| 态 | 表现 |
|----|------|
| 加载 | 版本徽标「加载中」；树骨架 |
| 空 | 无自建连接：「+ 新建连接」引导（系统只读区仍显示） |
| 出错 | 顶栏红色横幅；SQL 错误显示在结果区 |
| 无权限 | 401 横幅，不假装有数据 |
| 正常 | 树可展开、SQL 可跑、审批可弹 |

## 5. 刷新恢复（S-R）

浏览器刷新后恢复：连接列表、当前选中连接、编辑器草稿（每连接一份，localStorage，≤64KB）。**不恢复**：密码、结果集、待审批弹窗（待审批项从服务端队列重新拉取）。
