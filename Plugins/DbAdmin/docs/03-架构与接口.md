# 03 · 架构、数据模型与 HTTP 接口

## 1. 执行链路（定稿：XCode `DAL`）

```
Controller / ToolFunction
  → SqlGuard（分类 + 硬拒）  → ApprovalQueue（AskWrite）
  → DbConnectionService.Resolve(connId)
      系统连接：直接用已注册 ConnName（宿主 / PluginDbs），标记 ReadOnly
      用户连接：ConnName = "DbAdminU_<id>"，首次 DAL.AddConnStr(name, connStr, null, provider)
  → var dal = DAL.Create(name)
  → dal.Tables（schema） / dal.Query(sql, params)（读） / dal.Execute(sql, params)（写）
  → ResultLimiter（Agent：1000 行 / 256KB；UI：分页）
  → AuditWriter（脱敏）
```

- 一律参数化（字典或 `IDataParameter[]`）；分页由服务端包装，不信任客户端拼 LIMIT  
- 用户连接 ConnName 前缀 `DbAdminU_` 隔离，**不得**写入 `XCodeConfig.PluginDbs`，不得与宿主 ConnName 重名  
- 只读判定在服务端：系统连接对 `Execute` 一律硬拒（不仅靠 UI）  
- 驱动缺失：捕获 provider 加载异常 → 返回 `code=driver_missing` + 包名提示

## 2. 插件自有数据（ConnName `DbAdmin`，`Data/Model.xml` → xcode）

| 实体 | 关键字段 |
|------|----------|
| `DbConnection` | Id, Name, Provider, Mode(form/connstr), Host, Port, Database, UserName, **PasswordEnc**, ConnStrEnc, Readonly, CreateTime, UpdateTime |
| `DbQueryHistory` | Id, ConnectionId, SqlRedacted, Kind(read/write), RowCount, ElapsedMs, Success, Error, Source(ui/agent), CreateTime |
| `DbApproval` | Id, ConnectionId, SqlRedacted, Kind, Destructive, Status(pending/approved/rejected/expired), Source, CreateTime, ResolveTime |
| `DbAuditLog` | Id, Kind, ConnectionId, SqlRedacted, Decision, Detail, CreateTime |

- `Data/DbAdminTables.cs` 的 `EnsureCreated()` 在插件启动路径调用  
- 唯一性（连接名）直查 DB，不用 `Meta.Cache`  
- 业务写 `.Biz.cs`；密码字段加解密在 Biz 层  
- 审批中的原始 SQL 仅内存持有（批准后执行），落库为脱敏版

## 3. HTTP（前缀 `/api/db-admin/*`，类级 `[Authorize("ApiKeyPolicy")]`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/providers` | provider 列表 + `driverAvailable` |
| GET | `/connections` | 系统只读 + 用户连接；密码掩码 `****` |
| POST | `/connections` | 新建（用户连接） |
| PUT | `/connections/{id}` | 编辑；密码空 = 不改 |
| DELETE | `/connections/{id}` | 仅删配置（二次确认），**不删库文件** |
| POST | `/connections/test` | 测连（未保存的表单也可）；返回 ok / error / driver_missing |
| GET | `/connections/{id}/tables` | 表/视图 |
| GET | `/connections/{id}/tables/{table}` | 列、主键、索引 |
| POST | `/query` | `{connectionId, sql, params?, page, pageSize}` → 只读结果 / 或 `awaiting_approval` / `rejected` |
| GET | `/approvals` · POST `/approvals/{id}/resolve` | 审批队列 |
| GET | `/history` · GET `/audit` | 历史、审计（分页过滤） |
| GET/PUT | `/permission-mode` | 查看 / 修改当前模式 |

错误统一 `{code, message}`，`code ∈ rejected_hard | readonly_connection | driver_missing | sql_error | not_found | unauthorized`。
