# 04 · 权限、安全与审计（含 Agent 工具）

## 1. 连接分级

| 连接 | 来源 | 读 | 写 |
|------|------|----|----|
| 系统只读 | 宿主库 + `XCodeConfig.PluginDbs` | ✅ | ❌ **硬拒**（任何模式） |
| 用户连接 `DbAdminU_*` | 用户在 UI 新建 | ✅ | 按权限模式（默认 AskWrite） |

## 2. 权限模式

| 模式 | 行为 |
|------|------|
| **AskWrite**（默认） | SELECT/WITH 自动；DML/DDL 询问；破坏性审批后二次确认；硬拒仍拦 |
| **Auto** | 普通 DML/DDL 自动；破坏性仍询问 + 二次确认；硬拒仍拦 |
| （Agent） | 仅用 `db_set_permission_mode` 改**会话级**模式，不改全局默认 |

## 3. SqlGuard 分类

| 类别 | 示例 | 处理 |
|------|------|------|
| 只读 | `SELECT` / `WITH … SELECT` / `PRAGMA table_info` 类元数据 | 自动，强制上限 |
| 普通写 | `INSERT` / 带 WHERE 的 `UPDATE`·`DELETE` / `CREATE` / `ALTER ADD` | AskWrite |
| 破坏性 | `DROP TABLE/VIEW/INDEX` / `TRUNCATE` / `ALTER … DROP` | AskWrite + 二次确认 |
| **硬拒** | 无 WHERE 的 `UPDATE`/`DELETE`；多语句（`;` 分隔 >1 条，忽略字符串与注释内）；`DROP DATABASE`/`DROP SCHEMA`；`ATTACH`/`DETACH`；系统只读连接上的任何非只读语句；`xp_cmdshell`/`COPY … PROGRAM`/`LOAD_FILE` 等越界到 shell/文件的语句 | 直接拒绝，记审计 |

分类先剥注释与字符串字面量再判；无法确定类别的一律按「普通写」询问（fail-closed）。

## 4. Agent 工具（toolPrefix `db`）

| 优先级 | 工具 | 权限级别 | 说明 |
|--------|------|----------|------|
| Must | `db_list_connections` | 只读·无副作用 | 列连接（id / name / provider / kind / readonly / writePolicy + 本会话模式）；无主机、库路径、账号、密码、连接串 |
| Must | `db_list_tables` | 只读·无副作用 | `{connectionId}` |
| Must | `db_describe_table` | 只读·无副作用 | `{connectionId, table}` → 列/主键/索引 |
| Must | `db_query_readonly` | 只读（系统库可用） | `{connectionId, sql, params?, maxRows?, sessionId?}`；仅 SELECT / WITH（PRAGMA、SHOW、写语句返回 `not_readonly_sql`）；默认 200 行，硬上限 1000 行 / 256KB，返回 `truncated`；password/secret/token/connstr 类列掩码 |
| Must | `db_execute_write` | 写·受审批（仅用户连接） | `{connectionId, sql, params?, sessionId?}`；AskWrite 返回 `{status:"awaiting_approval", approvalId}`；硬拒返回 `rejected_hard`；系统库或只读连接返回 `readonly_connection`；只读语句返回 `use_query_readonly` |
| Should | `db_set_permission_mode` | 会话级配置 | `{mode: AskWrite\|Auto, sessionId}`；只改会话级，全局默认只能在 UI 改 |
| Should | `db_resolve_approval` | 代用户处理审批 | `{approvalId, approve, userConfirmationQuote?, sessionId?}`；approve=false 随时可用；approve=true 必须带用户原话（否则返回 `user_confirmation_required`）；破坏性语句一律返回 `confirmation_required`，只能在 UI 二次确认 |
| 不做 | Agent 建/改/删连接 | — | — |
| 下里程碑 | `db_explain` | — | — |

- 工具扩展点 Id 形如 `db-admin.query_readonly`。构造函数不注入宿主契约，执行期用 `CreateHostScope` 获取 `DbAdminAgentService`（铁律 26）。
- 回包统一。成功为 `{success:true, tool, status, data, hint}`，失败为 `{success:false, tool, status, code, message, hint}`。hint 告诉模型下一步该做什么，例如系统库只读时让用户新建可写连接、遇到硬拒时提示不得改写绕过。
- 出口两道擦除：`SqlRedactor.RedactText`，然后把已存的明文密码、连接串逐字替换成 `****`（只替换 JSON 字符串值）。由单测 `Secrets_NeverInAnyToolOutput_IncludingErrors` 守住。
- 评测集见 [07-Agent工具评测.md](./07-Agent工具评测.md)。

## 5. 审计与脱敏

- 审计 `kind`：`conn_create` / `conn_update` / `conn_delete` / `conn_test` / `query` / `classify` / `approval_*` / `write_result` / `rejected` / `permission_mode`  
- 只存 `sqlRedacted`：参数值、字符串字面量中疑似密钥（`password=`、`pwd=`、Bearer、连接串）替换为 `****`  
- 密码：DB 加密字段；GET 掩码；审计、历史、chat 工具回包、日志、CT fixture **均无明文**
