# 06 · UI / 交互评审稿（正式验收清单 · 已定稿）

> **炳宏定稿（2026-11-04）**：下列清单锁定，可叫前后端 / AI / 测试；每态截图。CT 画廊：`ForgeSelf.Web` → `pnpm run ct:server` → 侧栏 DbAdmin。

## 1. 屏幕 / 状态清单

| ID | 状态 | 用户可见要点 | 验收要点（截图） |
|----|------|--------------|------------------|
| S0 | **空态** | 无自建连接；系统只读区可见；「+ 新建连接」引导 | 引导可点；系统库带 🔒 |
| S1 | **连接表单** | SQLite 文件路径表单；密码遮罩 | 保存落盘；校验失败留窗 |
| S2 | **Schema 树** | 连接 → 表 → 列（类型/PK） | 展开正确；只读连接徽标 |
| S3 | **只读结果** | SELECT 结果格 + 分页 + 耗时 | 分页边界正确；大结果不卡 |
| S4 | **写审批** | 审批弹窗（语句、类型、来源）；破坏性再二次确认 | 批准后执行；拒绝不执行；审计有记录 |
| S5 | **失败** | SQL 错误 / 硬拒 / 只读连接写入被拒 | 红条原因可见；不弹审批 |
| S6 | **审计** | 抽屉过滤浏览 | 含 query/approval/rejected |
| S7 | **脱敏** | 连接 GET、历史、审计中密码与密钥为 `****` | 全页面搜不到明文 |
| S8 | **Agent 工具回显** | 聊天中 `db_*` 调用结果；写挂起 `awaiting_approval` 并在 UI 出审批 | 1000 行 / 256KB 截断 `truncated=true` |
| S9 | **多 provider 配置** | provider 下拉、表单↔连接串、测连 成功 / 失败 / 驱动缺失；「未实测」标注 | 三种测连结果各一张截图 |
| S-R | **刷新恢复** | 刷新后连接列表、当前连接、编辑器草稿恢复 | 无密码、无结果集残留；待审批从服务端重拉 |
