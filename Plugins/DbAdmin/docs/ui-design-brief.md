# 数据库管理 · UI 设计摘要（给设计师）

## 功能

- 左栏：「+ 新建连接」、系统只读连接（🔒）、我的连接；展开为表 → 列 schema 树  
- 右区：SQL 编辑器（Ctrl+Enter）、结果格（分页）、耗时/影响行数、历史  
- 连接表单：provider 下拉（全部可选，无「需驱动」灰标）、表单↔连接串、测连（成功/失败，失败直接显示底层错误）、「未实测」标注  
- 审批弹窗 + 破坏性二次确认；审计抽屉；权限徽章；版本徽标  

## 五态

| 态 | 表现 |
|----|------|
| 加载 | 版本徽标「加载中」、树骨架 |
| 表加载 | 点击连接后节点下局部 spinner「加载表…」；完成前不显示「（无表）」 |
| 空 | 无自建连接引导新建 |
| 出错 | 红色横幅 / 结果区错误 |
| 无权限 | 401 横幅 |
| 正常 | 树、执行、审批可用 |

## 视觉状态（主题）

- 左栏连接节点：未选默认态；选中态 `.node.on` 背景 `--el-color-primary-light-8`、文字 `--el-text-color-primary`。
- 亮色：`light-8 #F0B83B` + `#14110F` ≈10.3:1；暗色：`light-8 #78350F` + `#F4F0E7` ≈7.98:1（2026-11-06 修复，PC-025）。
- 状态标签 / 信息横幅：`--el-color-primary-light-9` 底 + `--el-color-primary` 字，暗色 ≥4.5:1。
- 验收：亮/暗两态各截图；选中行、标签、横幅用 `getComputedStyle` 实测对比度并记数值（默认浅色 e2e 不算暗色验证）。

## 用户旅程

1. 新建连接 → 测连 → 保存  
2. 展开 schema → 写 SQL → 只读直接出结果 / 写语句弹审批  
3. 批准（破坏性再确认）→ 看影响行数 → 审计回看；刷新后草稿仍在
