# 数据库管理 · UI 设计摘要（给设计师）

## 功能

- 左栏：「+ 新建连接」、系统只读连接（🔒）、我的连接；连接下可过滤表名（`表名过滤…`，无匹配显示「无匹配表」）、`↻` 刷新表；展开为表 → 列 schema 树。**点表名行 = 新建/聚焦该表的查询标签并展开列**；点 `▸` 只展开列、不开标签
- 右区：**多标签查询工作区**（同表同名只聚焦不新建、各标签 SQL/结果互不覆盖；最多 12 个，满则提示）；标签条右侧 `+` 新建自由查询；关标签后右邻优先激活，全部关闭显示空态
- 编辑器：有选区时「执行」按钮变「执行选中」并提示「仅执行选中」；无选区执行全部；**多条语句逐条执行**，结果区按语句分「结果 1 / 结果 2 …」标签条（单语句不显示标签条），每条带状态点（成功/失败/待审批/未执行），失败即停且后续标「未执行（第 N 条失败）」
- 结果格：分页、状态栏「N 行 · X ms」（写语句「影响 N 行」）、范围提示；工具按钮「复制整行」（先点行选中）、「导出 CSV」（当前结果当前页，文件名 `<表或连接>-r<结果>-p<页>-<yyMMddHHmm>.csv`）、双击单元格看详情（NULL 与长文本区分显示，Esc 关闭）
- 连接表单：provider 下拉（全部可选，无「需驱动」灰标）、表单↔连接串、测连（成功/失败，失败直接显示底层错误）、「未实测」标注、**默认表（可选，仅本机）**：填了则点该连接直接打开这张表的查询标签；留空则点连接只展开并加载全部表（不新建标签）
- 审批弹窗 + 破坏性二次确认；审计抽屉；权限徽章（AskWrite 等）；版本徽标

## 五态

| 态 | 表现 |
|----|------|
| 加载 | 版本徽标「加载中」、树骨架 |
| 表加载 | 点击连接后节点下局部 spinner「加载表…」；完成前不显示「（无表）」 |
| 空 | 无自建连接引导新建 |
| 出错 | 红色横幅 / 结果区错误 |
| 无权限 | 401 横幅 |
| 正常 | 树、执行、审批可用 |

## 视觉状态（主题）

- 左栏连接节点：未选默认态；选中态 `.node.on` 背景 `--el-color-primary-light-8`、文字 `--el-text-color-primary`。
- 亮色：`light-8 #F0B83B` + `#14110F` ≈10.3:1；暗色：`light-8 #78350F` + `#F4F0E7` ≈7.98:1（2026-11-06 修复，PC-025）。
- 状态标签 / 信息横幅：`--el-color-primary-light-9` 底 + `--el-color-primary` 字，暗色 ≥4.5:1。
- 验收：亮/暗两态各截图；选中行、标签、横幅用 `getComputedStyle` 实测对比度并记数值（默认浅色 e2e 不算暗色验证）。

## 用户旅程

1. 新建连接 → 测连 → 保存  
2. 展开 schema → 写 SQL → 只读直接出结果 / 写语句弹审批  
3. 批准（破坏性再确认）→ 看影响行数 → 审计回看；刷新后草稿仍在
