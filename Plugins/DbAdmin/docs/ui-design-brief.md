# 数据库管理 · UI 设计摘要（给设计师）

## 功能

- 左栏：「+ 新建连接」、系统只读连接（🔒）、我的连接。一个筛选框，占位「筛选连接、库或表」：连接名、库名、表名都能中；整条连接都不中则整条隐藏。连接名命中时，下面仍只留中了的库和表；库一个都不中显示「无匹配库」，表一个都不中显示「无匹配表」。`↻` 刷新当前连接。
- **MySQL / SQL Server / PostgreSQL**：点连接先出「加载数据库…」，再出全部库。系统库排在后面，带「系统」；和这条连接里保存的库同名的带「默认」。点某个库才出「加载表…」和表。加载没结束之前，不出现「未枚举到数据库」或「（无表）」。
- **SQLite、系统只读连接、Oracle**：不出现库这一层。点连接直接「加载表…」，再出表 → 列。
- **点表名行 = 新建/聚焦该表的查询标签并展开列**；点 `▸` 只展开列、不开标签。表上右键：复制表名、查看结构（展开列）、只刷新这一张表的列。不同库里的同名表是两张标签，不会混成一张。
- 右区：**多标签查询工作区**（同表同名只聚焦不新建、各标签 SQL/结果互不覆盖；最多 12 个，满则提示）；标签条右侧 `+` 新建自由查询；关标签后右邻优先激活，全部关闭显示空态
- 编辑器：有选区时「执行」按钮变「执行选中」并提示「仅执行选中」；无选区执行全部；**多条语句逐条执行**，结果区按语句分「结果 1 / 结果 2 …」标签条（单语句不显示标签条），每条带状态点（成功/失败/待审批/未执行），失败即停且后续标「未执行（第 N 条失败）」
- 结果格：分页、状态栏「N 行 · X ms」（写语句「影响 N 行」）、范围提示。执行过程中结果区是骨架，不出现「0 行」，也不出现「结果将显示在这里」。成功但没有行时，结果区写「0 行（X ms）」；没有耗时就写「0 行」。工具：「复制整行」（先点行号选中整行）、「导出 CSV」（当前页）、「导出全部」（从第 1 页拉到最后，最多 50 页；失败会说明停在第几页，已经拿到的行仍下载）、「导出 JSON」「导出 INSERT」（都只导出当前页；自由查询没有表名时 INSERT 灰色，悬停说明原因）。双击单元格看详情（NULL 与长文本区分，Esc 关闭）。点一个格子后再 Ctrl+C，或右键「复制单元格」；列头右键「复制列名」。NULL 复制出来是 NULL。拖列头右缘改列宽，最窄 48 像素，双击右缘按当前页内容撑开。
- 连接表单：provider 下拉（SQLite / MySQL / PostgreSQL / SQL Server / Oracle，全部可选，无「需驱动」灰标）、表单↔连接串、测连（成功/失败，失败直接显示底层错误）、「未实测」标注。MySQL / SQL Server / PostgreSQL 的库名字段叫「默认数据库」，可以留空，占位「可留空，打开后列出全部数据库」；PostgreSQL 下面多一句「留空时先连维护库 postgres，再列出其它库」。SQLite 仍是文件路径。Oracle 的字段叫「服务名」，空着保存会提示「请填写服务名」。**默认表（可选，仅本机）**：SQLite 与 Oracle 填了就在点连接时打开这张表，留空只出表清单。MySQL / SQL Server / PostgreSQL 要同时有已保存的默认库和本机默认表，才会在库列出来之后展开那个库并打开表；否则只列出库。
- 审批弹窗 + 破坏性二次确认；审计抽屉；权限徽章（AskWrite 等）；版本徽标

## 五态

| 态 | 表现 |
|----|------|
| 加载 | 版本徽标「加载中」、树骨架 |
| 库加载 | MySQL / SQL Server / PostgreSQL 点连接后，节点下「加载数据库…」；结束前不出现「未枚举到数据库」 |
| 表加载 | 点库之后（或 SQLite / 系统连接 / Oracle 点连接之后）节点下「加载表…」；完成前不显示「（无表）」 |
| 空 | 无自建连接引导新建 |
| 出错 | 红色横幅 / 结果区错误 |
| 无权限 | 401 横幅 |
| 正常 | 树、执行、审批可用 |

## 视觉状态（主题）

- 左栏连接节点：未选默认态；选中态 `.node.on` 背景 `--el-color-primary-light-8`、文字 `--el-text-color-primary`。
- 亮色：`light-8 #F0B83B` + `#14110F` ≈10.3:1；暗色：`light-8 #78350F` + `#F4F0E7` ≈7.98:1（2026-11-06 修复，PC-025）。
- 状态标签 / 信息横幅：`--el-color-primary-light-9` 底 + `--el-color-primary` 字，暗色 ≥4.5:1。
- 验收：亮/暗两态各截图；选中行、标签、横幅用 `getComputedStyle` 实测对比度并记数值（默认浅色 e2e 不算暗色验证）。

## 点什么出现什么（本批）

| 点什么 | 出现什么 |
| --- | --- |
| 点 MySQL / SQL Server / PostgreSQL 连接 | 先「加载数据库…」，再出全部库。系统库在后面并标「系统」。和已保存库同名的标「默认」。 |
| 点其中一个库 | 「加载表…」，然后是这个库的表。查询和看列都针对这个库。 |
| 点 SQLite、系统连接或 Oracle | 没有库这一层，直接「加载表…」再出表。 |
| 点 `↻` | 服务器型连接重新拉库，并刷新已经展开的库里的表。其它连接只刷新表。 |
| Ctrl+W | 关掉当前查询标签。浮层开着时不关标签。 |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一个 / 上一个查询标签。只剩一张就停在原标签。浮层开着不切换。 |
| Ctrl+T | 等同点「+ 新查询」。还没选连接时不新建。 |
| 拖结果列头右缘 / 双击右缘 | 列变宽或变窄，不会窄于 48 像素；双击按当前页文字撑开。刷新页面后宽度不保留。 |
| 点一个单元格，再 Ctrl+C 或右键「复制单元格」 | 剪贴板是这个格子的文字。还没点过格子时，Ctrl+C 不写入剪贴板。 |
| 列头右键「复制列名」 | 剪贴板是列名。 |
| PgUp / PgDn / Home / End | 上一页、下一页、第一页、最后一页。焦点在输入框里，或浮层开着时，不抢这些键。不知道一共有多少行时，End 不翻页。 |
| 表节点右键 | 菜单：复制表名、查看结构、只刷新该表。点菜单外面或按 Esc 关掉菜单。 |
| 双击自由查询标签的标题 | 变成输入框。Enter 保存，Esc 取消。清空后标题回到「新查询」。表标签不能改名。 |
| 查询还在跑 | 结果区只见表格骨架。 |
| 查询成功但 0 行 | 结果区写「0 行（X ms）」；没有耗时就写「0 行」。 |
| 点「导出全部」 | 下载一份合并的 CSV，文件名里的页码是 all。按钮变成「导出中…」，这时再点不会再导一次。中途失败会在横幅写停在第几页，已经拿到的行仍会下载。 |
| 点「导出 JSON」 | 下载当前页，一行一个对象，空值是 null。 |
| 点「导出 INSERT」 | 下载当前页，一行一条 INSERT。自由查询没有表名时按钮不可点，悬停说明原因。 |

## 用户旅程

1. 新建连接 → 测连 → 保存。服务器型连接可以不填库名。  
2. 点连接看全部库 → 点库看表 → 写 SQL → 只读直接出结果 / 写语句弹审批。SQLite 与 Oracle 仍是点连接直接看表。  
3. 批准（破坏性再确认）→ 看影响行数 → 审计回看；刷新后草稿仍在。自由查询的自定义标题也会留下来。
