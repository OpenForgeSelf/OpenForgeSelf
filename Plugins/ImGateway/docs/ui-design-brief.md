# IM 网关 · 交互设计说明（ui-design-brief）

> 面向设计师的界面交互说明（设计师不读代码）。对应版本：im-gateway 2.1.1（PILOT-078 + 2026-10-31 方向/几何修复批）。
> 设计令牌：项目 themes/ tokens 与 `--el-*` 变量；禁止裸色值。UI/UX 规范唯一真源 = 仓库根 `DESIGN.md`（色板/组件规格/三禁红线/门禁三步）；更新本文件 = 改了界面交互就同步。

## 一、这个页面是干什么的

IM 网关把企业微信（智能机器人）接入 AI Agent：用户在企微里发消息 → 网关转给 AI → AI 回复发回企微。
本插件页面以前只能「配置机器人」，看不到「谁在用、聊了什么、有没有失败」。
2.1.0 起页面 = **会话视图（默认）+ 配置视图（切换）**，让网关从黑盒变成一个「可回看的聊天窗口」。

## 三、用户旅程（主链路）

1. **打开页面** → 默认会话视图。左栏列出所有「发过消息的 IM 用户」（像微信联系人：图标+名字+最后一条消息预览+相对时间），按最近消息倒序；顶部一条状态灯显示企微长连接是否在线。
2. **点一个联系人** → 条目高亮，右栏加载与 TA 的消息线程：AI 回复=**左侧**气泡，用户发来的消息=**右侧**气泡（方向语义=需求拍板项，2026-10-31 用户确认），每条带时间；回复失败的显示错误气泡（带失败原因摘要）。
3. **消息很多** → 线程底部「加载更多」按钮，点击前插更早消息，当前位置不跳动；没有更早的就隐藏按钮。
4. **放着不动** → 每 12 秒安静刷新（列表与当前线程增量更新，无闪烁）；新消息自动出现在列表预览和线程里（线程只在用户已位于底部时才自动滚动）。
5. **改配置** → 点右上「配置」→ 切换到配置视图（原有的机器人开关、BotId/Secret、扫码授权、绑定 Agent模型、灯、重、保存全部原样）；点「返回会话」切回。

## 四、五态约定

| 状态 | 左栏（联系人列表） | 右栏（消息线程） |
| --- | --- | --- |
| 加载 | 条目占位（轻量，无转圈大动画） | 线程区「加载中…」细文案 |
| 空（从未有人发消息） | 引导空态：「还没有 IM 用户发来消息」+「去配置」按钮 | 未选中联系人时：「从左侧选择一个联系人查看消息」 |
| 空（有联系人但无消息记录） | 正常显示条目，预览=「暂无消息记录」 | 「该联系人还没有消息记录」 |
| 出错（请求失败） | 保留旧列表 + 顶部错误条（可重试语义：下轮轮询自动重试） | 保留旧线程 + 细错误提示；不闪空 |
| 正常 | 见旅程 | 见旅程 |

无权限态：未带令牌访问时宿主层返回 401（页面显示宿主统一登录提示），插件内不重复处理。

## 五、细节规则（对齐设计系统）

- 长文本：列表预览单行省略（…）；气泡内长文本按词换行，不横向撑破。
- 失败可见：`error` 气泡用警示色（--cinnabar-*）+ 失败原因一行摘要；不用红色大 banner。
- 相对时间：3 分钟前 / 昨天 21:16 / 2026-10-30 21:16 三级回落。
- 通道停用：联系人列表照常显示历史（数据是事实）；状态灯显示未连接即可，不额外吓人。
- 无任何删除/撤回操作：本页纯只读 + 配置，无破坏性操作、无二次确认弹窗。
