# IM 网关 · 交互设计说明（ui-design-brief）

> 面向设计师的界面交互说明（设计师不读代码）。对应版本：im-gateway 2.1.1（PILOT-078 + 2026-10-31 方向/几何修复批）。
> 设计令牌：项目 themes/ tokens 与 `--el-*` 变量；禁止裸色值。UI/UX 规范唯一真源 = 仓库根 `DESIGN.md`（色板/组件规格/三禁红线/门禁三步）；更新本文件 = 改了界面交互就同步。

## 一、这个页面是干什么的

IM 网关把企业微信（智能机器人）接入 AI Agent：用户在企微里发消息 → 网关转给 AI → AI 回复发回企微。
本插件页面以前只能「配置机器人」，看不到「谁在用、聊了什么、有没有失败」。
2.1.0 起页面 = **会话视图（默认）+ 配置视图（切换）**，让网关从黑盒变成一个「可回看的聊天窗口」。

## 三、用户旅程（主链路）

1. **打开页面** → 默认会话视图。左栏列出所有「发过消息的 IM 用户」（像微信联系人：图标+名字+最后一条消息预览+相对时间），按最近消息倒序；顶部一条状态灯显示企微长连接是否在线。
2. **点一个联系人** → 条目高亮，右栏加载与 TA 的消息线程：AI 回复=**左侧**气泡，用户发来的消息=**右侧**气泡（方向语义=需求拍板项，2026-10-31 用户确认），每条带时间；回复失败的显示错误气泡（带失败原因摘要）。
3. **消息很多** → 线程底部「加载更多」按钮，点击前插更早消息，当前位置不跳动；没有更早的就隐藏按钮。
4. **放着不动** → 每 12 秒安静刷新（列表与当前线程增量更新，无闪烁）；新消息自动出现在列表预览和线程里（线程只在用户已位于底部时才自动滚动）。
5. **改配置** → 点右上「配置」→ 切换到配置视图（原有的机器人开关、BotId/Secret、扫码授权、绑定 Agent模型、灯、重、保存全部原样）；点「返回会话」切回。

## 四、五态约定

| 状态 | 左栏（联系人列表） | 右栏（消息线程） |
| --- | --- | --- |
| 加载 | 条目占位（轻量，无转圈大动画） | 线程区「加载中…」细文案 |
| 空（从未有人发消息） | 引导空态：「还没有 IM 用户发来消息」+「去配置」按钮 | 未选中联系人时：「从左侧选择一个联系人查看消息」 |
| 空（有联系人但无消息记录） | 正常显示条目，预览=「暂无消息记录」 | 「该联系人还没有消息记录」 |
| 出错（请求失败） | 保留旧列表 + 顶部错误条（可重试语义：下轮轮询自动重试） | 保留旧线程 + 细错误提示；不闪空 |
| 正常 | 见旅程 | 见旅程 |

无权限态：未带令牌访问时宿主层返回 401（页面显示宿主统一登录提示），插件内不重复处理。

## 五、细节规则（对齐设计系统）

- 长文本：列表预览单行省略（…）；气泡内长文本按词换行，不横向撑破。
- 失败可见：`error` 气泡用警示色（--cinnabar-*）+ 失败原因一行摘要；不用红色大 banner。
- 相对时间：3 分钟前 / 昨天 21:16 / 2026-10-30 21:16 三级回落。
- 通道停用：联系人列表照常显示历史（数据是事实）；状态灯显示未连接即可，不额外吓人。
- 无任何删除/撤回操作：本页纯只读 + 配置，无破坏性操作、无二次确认弹窗。

## 任务网关小节（2.2.0 设计新增 · design · 2026-11-03）

> 对应 02-spec FR-6/FR-7 与「FR-7 视觉与交互规格（design · 2026-11-03）」（实现级规格以彼为准）。本节面向设计师：只写功能、旅程与界面行为。

### 功能是什么

在企微里发一条带前缀的消息（如「/task 整理本周周报」），网关把这句话作为任务派给 AI Agent：立刻回「已建任务」回执，之后在后台盯进度，任务完成/失败/卡住时**主动**把结果发回企微。任务因工具授权卡住时推送「审批卡」，用户直接在 IM 回复关键字（默认「同意 #编号」）即可放行，不必去宿主页面。该能力默认关闭，由本小节设置卡控制。

### 界面位置与布局

配置视图内、企业微信通道卡下方新增「任务网关」卡，形态与通道卡一致：

- 卡头：名称 +「已启用/未启用」徽标 + 一句职责说明；右上角总开关。
- 分区 A「派发规则」：命令前缀（可增删的标签输入，至少 1 条）｜默认 Agent（下拉：首项「跟随会话绑定」，其余来自智能体名册）｜轮询间隔（数字 + 「秒」，默认 10）。
- 分区 B「IM 审批」：子开关（带说明：任务卡住时经 IM 推送审批卡）+ 同意关键字、拒绝关键字（同样式标签输入，默认 同意/批准、拒绝/驳回）。
- 尾注说明框：默认值、生效时机、关键字只在有待审批任务时才拦截（否则走普通聊天，零误伤）。
- 不新增保存按钮：与面板一致，用底部唯一「保存配置」。

### 用户旅程（设计师自查用）

1. 打开配置 → 通道卡下方见「任务网关」卡：总开关默认关，A/B 分区灰显并带原因「任务网关未启用——打开右上开关后可编辑」。
2. 打开总开关 → 灰显解除、徽标变「已启用」，数值保留不丢。
3. 按需改前缀/默认 Agent/轮询间隔，开 IM 审批并确认关键字 → 点「保存配置」→ 顶部绿色提示「已保存并重新加载配置」。
4. 企微发「/task 写个xx报告」→ 数秒内收回执（编号 + 被指派 Agent）。
5. 任务完成 → 企微自动收到结果；失败收到原因；卡住（等审批）→ 收到审批卡 → 回「同意 #12」→ 收到「已同意，任务继续执行」。
6. 不配置/关总开关 → 一切照旧，聊天链路零变化。

### 交互行为约定

| 交互点 | 行为 |
| --- | --- |
| 总开关 off | A/B 分区禁用 + 可见原因；控件不隐藏、数值不丢 |
| 前缀/关键字删到 0 条 | 「保存配置」被阻断，顶部红条写明字段与原因 |
| 轮询间隔越界（<3 秒等） | 行内红字提示，保存阻断 |
| 名册加载失败 | 下拉置灰 + 提示「可留空走默认链」，不白屏 |
| 子开关 off | 两个关键字字段禁用 + 原因提示 |
| 保存成功/失败 | 复用顶部提示条（绿/红）；失败时表单保留输入 |

### 五态

加载=表单先以默认值呈现、数据回来后回填（不空屏）；空=不存在「无配置」态（后端缺省值兑底）；出错=顶部红条 + 重试语义（再点保存或刷新）；无权限=宿主统一登录提示；正常=表单可编辑。视觉：全部复用面板既有组件形态与 token，无新增裸色值。
