## 一、产品与角色

**一句话:** MCP 中心让本平台的全部工具,通过一个统一的 MCP 地址提供给外部客户端使用;同时可以反过来连接外部 MCP 服务器,把它们的工具纳入同一个入口。

**入口:** 只有一个菜单"MCP 中心",路径 `/mcp-center`,不新增一级菜单。

**核心概念(全稿只用这些词):**
- **网关:** 本平台对外开放的 MCP 服务,有地址、端口、访问令牌。对外只暴露一个万能工具 `universal_tool`。
- **外部服务器:** 本平台作为客户端去连接的第三方 MCP 服务器,支持三种传输:stdio(本地命令)、Streamable HTTP、HTTP+SSE(旧版)。
- **工具:** 服务器提供的一项能力。外部服务器的工具对外统一命名为 `mcp.<服务器id>.<工具名>`。
- **令牌:** 外部客户端连接网关时带的访问凭据。
- **测试台:** 选一个工具、填参数、发起一次真实调用并看结果的工作区。

**角色:**
- **平台管理员:** 设置网关端口、地址、令牌、跨域来源;添加和维护外部服务器;开关工具。
- **工具使用者:** 在测试台里试调用工具,看结果。
- **接入方开发者:** 拿到网关地址和令牌,把某个客户端(如 dsh)接进来。只看"客户端接入"区。

## 二、全局规则(每个区都适用)

1. **五种状态:** 每个数据区画出加载、空、出错、无权限、正常。空态必须带"下一步动作"按钮。出错态带"重试"。
2. **禁用要说原因:** 禁用的按钮,悬停或旁边写具体原因,如"服务器已停用,先启用才能连接"。
3. **二次确认:** 删除、断开、清除令牌、保存会重启网关的配置、写入外部客户端配置,都要弹确认框,写清对象、后果、能否恢复。不使用浏览器自带的确认框。**清除令牌**和**无令牌且监听全部网卡**属高危,确认框视觉上要和普通确认明显不同。
4. **自动刷新不闪:** 状态刷新时,不丢滚动位置、不清空正在输入的内容、不整页闪。
5. **长文本:** 服务器名、命令、参数、地址、错误信息都要能超长。截断显示,悬停或点击可看全文。窄屏布局不破(窄视口下卡片标题不能逐字竖排,按钮不能溢出卡片边缘)。
6. **密钥:** 令牌、请求头里的密钥、环境变量里的密钥,只显示"已设置"或"****加末 4 位",永远不出现明文。输入时可临时显示,保存后不可回看。
7. **颜色:** 用 Element Plus 组件,颜色用 `--el-*` 变量和 Tailwind,不写裸色值,浅色和深色都要给。**状态不能只靠颜色**,必须配文字或图标。选中项的文字与背景对比度达到 WCAG AA。键盘可操作。
8. **加载指示:** 区块级加载用统一的遮罩或骨架,不能出现"遮罩不生效、空白等待"。
9. **术语一致:** 只用上文的概念词。不要混用"服务器/服务端/节点","工具/函数/能力","网关/代理"。
10. **示例数据:** 每个列表做 0 条、1 条、很多条三种情况,并包含超长服务器名、超长命令行、超长错误信息、超长工具描述。
11. **版本与地址:** 页头始终显示插件版本和网关地址。

## 四、模块(点什么 → 出什么)

### 模块 1:总览【新增】

**目的:** 打开页面第一眼回答三个问题:网关能不能用、安不安全、外部服务器连上了没有。

**内容:**
- **三张状态卡【已有,从原网关页上移】:**
  - 服务地址:显示完整地址;提示"客户端须使用 /mcp 路径,根路径会 404";按钮"复制地址";网关未运行时地址位显示"(未运行,暂无地址)",按钮禁用,原因"网关未运行"。点"复制"后按钮文字变"已复制",短暂后复原。
  - 运行状态:"正在监听"或"未运行",下方写"监听 地址:端口"。
  - 访问令牌:已设置时显示"已设置 ****加末4位";未设置时显示"未设置(无鉴权)"。
- **安全提示条【新增】:**
  - 令牌未设置:页面顶部常驻一条醒目的警示,文字"网关当前没有令牌,任何能访问该端口的人都能调用全部工具",按钮"去设置令牌"(跳到网关设置区并聚焦令牌输入)。
  - 令牌未设置且监听地址为全部网卡:警示升级为高危样式,文字补一句"并且局域网内可访问"。
  - 令牌已设置:不显示提示条。
  - 提示条不可永久关闭,只有设置了令牌才消失。
- **外部服务器概览【新增】:** 一行摘要"外部服务器 共 M 个,已连接 N 个,出错 K 个",点数字跳到"外部服务器"区并按该状态过滤。
- **最近错误【新增】:** 列出最近出错的外部服务器及错误信息(每条超长截断可看全文),每条有"去查看"。无错误时显示"暂无错误"。
- **快捷入口:** "添加外部服务器"、"打开测试台"、"客户端接入"。

**五态:** 加载中(三张卡骨架)、网关未运行(状态卡显示未运行,提示条说明原因)、出错(读配置失败,带重试)、无权限(提示"需要管理令牌才能查看网关配置",带"去登录或设置"动作)、正常。

### 模块 2:外部服务器【已有,重设计】

**数据:** ID(小写短横线,创建后不可改)、名称、传输类型、连接状态、对外命名空间 `mcp.<id>.<工具名>`、工具数、协议版本、服务器自报名称、最近错误、是否启用。

**列表:**
- 每个服务器一张卡:名称、状态标签(文字加图标)、传输类型标签、命名空间、工具数、协议版本、服务器自报名称、最近错误(截断,悬停看全)。
- 顶部:搜索框、状态过滤(全部/已连接/未连接/已停用/出错)、"新增服务器"按钮。
- 状态文字至少区分:已连接、未连接、已停用、出错。其余状态由设计师按现有数据补,并回写本文。

**卡片操作(按状态显示):**
- "连接":仅当已启用且未连接时出现;点击后按钮转圈,成功后状态变已连接并显示工具数;失败则状态变出错,错误信息写在卡上,同时弹出轻提示。
- "断开":仅当已连接时出现,点击先二次确认"断开后,通过 `mcp.<id>.` 调用该服务器工具会失败。可重新连接。"
- "测试":不改变连接状态,只检测可达。结果用浮层或行内提示显示"测试通过/测试失败"、消息和耗时(毫秒);点遮罩或关闭按钮可关。
- "工具":打开测试台(见模块 4),标题含服务器名。
- "编辑":打开表单弹窗,ID 只读。
- "删除":二次确认,写明"将从外部服务器配置中移除,其下 N 个工具对外立即不可用,不可恢复"。已连接的服务器,确认框额外提示"将先断开连接"。

**新增/编辑弹窗:**
- 顶部:"填入 DeepWiki 预设"按钮,旁注"官方公开端点,免鉴权,仅用于联调"。点击后填入预设值,已填内容被覆盖时先二次确认。
- 字段:ID(必填,提示"小写短横线,如 deepwiki",校验重复和格式)、名称(必填)、传输(下拉三选一:stdio(本地命令)/Streamable HTTP(MCP 2.0)/HTTP+SSE(旧版))。
- 传输为 HTTP 类:URL(必填)、请求头(多行,每行"键: 值")。
- 传输为 stdio:命令(下拉可选 npx、node、python、uvx、dotnet,也可手输)、参数(空格分隔)、环境变量(多行,每行"键: 值")。
- 切换传输时,不相关字段隐藏但保留已填内容,切回时恢复。
- 编辑时密钥类内容显示"****加末4位",并在旁边写"不改动则保留原密钥;要修改请整行重写为完整新值"。
- 勾选项:"保存后自动连接"。
- 底部预览:"对外统一工具名:mcp.<填写的ID>.<工具名>",ID 为空时显示 `<服务器id>` 占位。
- 按钮:取消、保存。保存时按钮转圈;校验失败的字段处就地报错;重复 ID 报"该 ID 已存在"。
- **WebSocket 传输【新增·占位】:** 传输下拉里多一项"WebSocket",置灰,悬停原因"暂不支持,后续版本提供"。

**工具清单快照【新增】:** 卡片上显示"工具清单快照于 <时间>",旁有"重新拉取"按钮(仅已连接时可点,未连接时禁用,原因"服务器未连接")。提示文字:"服务器新增工具后,需重新拉取或重连才能看到"。后续若支持服务器主动通知,此按钮保留为手动兜底。

**空态:** "还没有外部服务器",按钮"新增服务器"和"用 DeepWiki 预设试一下"。

### 模块 3:工具【已有,重设计】

**数据:** 工具名称、所属服务器、描述、分类、是否启用。

**列表:**
- 顶部:搜索框("搜索工具…",搜名称和描述)、分类过滤(全部/系统/文件/网络/数据/开发,分类来源见维护说明待确认)、服务器过滤。
- 表格列:工具名称、服务器、描述(截断,悬停看全)、状态开关、操作。

### 模块 4:测试台【已有,重设计】

**入口:** 外部服务器卡片的"工具"按钮;工具列表行的"打开测试台"。以宽对话框或整页抽屉呈现。窄屏时左右两栏变上下两栏。

**布局:**
- 左栏:该服务器的工具清单,每项显示工具名和描述(无描述时显示"(无描述)")。点击选中。
- 右栏:未选工具时提示"从左侧选一个工具,按它的参数说明发起调用";无可用工具时提示"无可用工具"。
- 左栏空态:"该服务器未暴露工具(或未连接)",带"去连接"按钮(未连接时)。

**选中工具后:**
- 标题:工具名、完整名称标签(`mcp.<id>.<工具名>`)、切换按钮"JSON 模式"/"切回表单模式"。
- 描述文字。
- **表单模式:** 按参数声明生成控件:枚举用下拉、布尔用开关、数字/整数用数字框(整数不允许小数)、其余用文本框,数组和对象用多行文本。每个字段显示名称、类型、"必填"标记和说明。工具没有声明参数时提示"该工具没声明参数,可直接调用"。
- **JSON 模式:** 一个多行输入框,占位示例 `{"key":"value"}`。JSON 不合法时就地提示。表单与 JSON 切换时内容互相带过去。
- **"将发送"预览:** 始终显示即将发出的参数 JSON。
- **"发起调用"按钮:** 点击转圈。有必填项未填时,按钮旁提示"必填未填:xxx、yyy"(此时按钮禁用,原因就是这句话)。
- **结果区:** 标签(成功/失败/工具返回错误,文字加图标)、耗时(毫秒)、结果文本(长文本可滚动、可复制)、"查看原始 JSON"开关。无文本内容时显示"(无文本内容)"。调用本身失败(如网络错误)用独立的错误条显示,不和工具返回的错误混在一起。
- 调用期间可以切换工具,但要提示"当前调用仍在进行"(是否支持取消:待定)。

### 模块 5:网关设置【已有,重设计】

**上半:当前状态,** 复用总览的三张状态卡,不重复实现两套。

**修改表单(字段与规则均为现有规则):**
- 监听端口:数字框,范围 1024–65535,旁注"范围 1024-65535"。越界就地报错。
- 监听地址:文本框,占位"127.0.0.1 / 0.0.0.0",旁注"0.0.0.0 表示局域网可访问"。填 0.0.0.0 时旁边出现警示"局域网内任何设备都能访问此端口"。
- 访问令牌:密码框(可显示/隐藏输入)。已设置时占位"留空保持不变(输入新值覆盖)";未设置时占位"输入令牌启用鉴权"。
- "清除当前令牌(使网关恢复无鉴权)"复选框:仅在已设置令牌时出现。勾选时表单内出现高危提示,保存时走高危确认。勾选后令牌输入框禁用,原因"已选择清除令牌"。
- 允许跨域来源:多行文本,每行一个完整 Origin(http/https + 主机 + 可选端口,不含路径),占位示例两行。旁注"留空则不允许跨域;只对 /mcp 生效;实际请求仍受令牌规则控制"。格式不对的行就地标红并指出是第几行。
- 会话模式:开关,两个标签"无状态"/"有状态"。无状态时旁注"推荐:不发会话 id,宿主或网关重启后客户端无需重连";有状态时旁注"握手签发 Mcp-Session-Id;重启后旧会话失效,客户端须重新连接"。
- 执行超时:数字框,单位秒,范围 1–3600,默认 300。旁注"外部 MCP 工具调用等待上限;改动后对新建或重连的连接生效"。
- 按钮:"保存并重启生效"。

**保存流程:**
1. 点保存,若有校验错误则就地提示,不弹窗。
2. 若本次修改会重启网关(端口、地址、令牌、跨域、会话模式),弹确认框,写明"将重启内置 MCP 服务,已连接的客户端可能断开"。仅修改执行超时时不弹此确认。
3. 保存中:按钮转圈,表单不可编辑,页头状态显示"正在重启…"。
4. 成功:提示"已生效",状态卡刷新。
5. 失败:提示"保存失败,已自动回滚到原配置",并显示失败原因。回滚后表单恢复为原值。
- 表单有未保存修改时,切换区或离开页面要提示"有未保存的修改"。

**五态:** 加载中、出错(读配置失败,带重试)、无权限、正常。

**目的:** 把本平台网关写进 dsh(DeepSeek Harness)等客户端的配置里。本区目前只有 dsh。

## 五、验收核对清单(逐条核对,每条给"通过/不通过")

**全局**
1. 每个数据区都有加载、空、出错、无权限、正常五种画面,空态都带下一步按钮。
2. 所有禁用按钮都能看到具体原因。
3. 没有浏览器自带的确认框,所有二次确认写清对象、后果、能否恢复。
4. 清除令牌、无令牌且监听全部网卡的确认或提示,视觉上与普通确认明显不同。
5. 任何位置令牌和密钥都不出现明文,只有"已设置"或"****加末4位"。
6. 状态都有文字或图标,不只靠颜色;选中项文字对比度达标。
7. 浅色、深色两套都有;键盘可完成主要操作。
8. 每个列表都有 0 条、1 条、多条三种示例,含超长名称、命令、错误信息。
9. 窄屏下卡片标题不竖排,按钮不溢出。
10. 刷新时滚动位置和输入内容不丢,不闪。

**总览**
11. 令牌未设置时,页面顶部有常驻警示,点"去设置令牌"能跳到并聚焦令牌输入。
12. 令牌未设置且监听全部网卡时,警示变为高危样式并多一句局域网说明。
13. 网关未运行时,地址位显示"(未运行,暂无地址)",复制按钮禁用并有原因。
14. 外部服务器摘要的数字可点,跳转后已按状态过滤。

**外部服务器**
15. 连接、断开、测试、工具、编辑、删除六个操作按状态正确显示或隐藏,断开和删除有二次确认。
16. 新增弹窗:三种传输的字段切换正确,切换后已填内容保留;ID 重复和格式错误就地报错;编辑时 ID 只读、密钥显示脱敏并有说明。

18. 对外工具名预览随 ID 实时变化。

**工具与测试台**
