## 1. 环境与夹具

正式复验环境：Linux 真实宿主产品页（独立 QA 实例与数据目录，不占用联调 7310，不杀 ST 7301 / 18765）。需求未要求 Windows 双端；I04 验的是约 320px 视口，不是另一套操作系统。F25 经能力中心调用工具，可用接口输出作辅证，工作台侧仍要截图证明没有工具目录页。

准备四类本机夹具目录（只读扫描，测试过程不得改其中文件，登记/导入也不得在目录里创建文件或执行 git / 包管理命令）：

| 夹具 | 用途 |
|------|------|
| P-plugins | 根目录有合法 `package.json`，`dependencies` / `devDependencies` / `optionalDependencies` 中同时包含应计入与不应计入的包，用于 F19 / F20 / F23 |
| P-empty | 无 `package.json`，或有清单但没有任何匹配规则的包，用于 F21 空态 |
| P-badjson | `package.json` 不是合法 JSON，用于 F19 扫描失败 |
| P-missing | 登记后把目录移走或改不可读，用于路径不可达（F08、第 3 节） |

P-plugins 识别矩阵（后端单测与宿主列表对照同一份）：

| 包名 | 是否计入 | 分组 |
|------|----------|------|
| `vite-plugin-foo`、`foo-vite-plugin`、`@vitejs/plugin-vue` | 是 | 构建 |
| `rollup-plugin-foo`、`unplugin-foo`、`foo-webpack-plugin`、`webpack-plugin-foo` | 是 | 构建 |
| `babel-plugin-foo`、`@babel/plugin-transform-foo` | 是 | 转译 |
| `eslint-plugin-foo`、`@scope/eslint-plugin-foo`、`prettier-plugin-foo` | 是 | 代码质量 |
| `eslint-config-foo` | **否**（配置包不是插件） | — |
| `@vue/cli-plugin-foo`、`vue-cli-plugin-foo` | 是 | 框架 |
| `vue`、`vite`、`lodash`、`eslint` 本体等不匹配规则的依赖 | 否 | — |

每条计入项至少展示：包名、声明版本、分组、来源（`package.json`）。不读取 `node_modules`，不展示「已安装 / 未安装」。

另备：一个由智能体来源（`ai-agent`）登记的项目，用于 F06；项目内至少两条可启动命令（其一带访问地址），用于 F07–F12、F23。

F09 停止反馈补充用例（v1.0.2，PILOT-087，对照 01-需求 F09 验收标准 AC-F09-1…7）：

- **T-F09-S1（AC-F09-1/2 停止成功）**：启动长驻命令 → 点「停止」→ 出现「已停止」toast + 日志「■ 已停止：…」行 + 状态收敛已结束 + 计数刷新。单测：`stop-feedback.spec.ts`（outcome=stopped）。
- **T-F09-S2（AC-F09-3 已不在运行）**：对已退出的进程点停止（宿主重启后或进程自行退出后）→ 提示「已不在运行」而非「停止失败」，状态收敛已结束并留痕。单测：`stop-feedback.spec.ts`（outcome=already-stopped）；后端三态契约：`SemsControllerTests`、`RunnerServiceTests.Stop_SecondCall_AfterStopped_ReturnsAlreadyStopped`。
- **T-F09-S3（AC-F09-4 失败可重试）**：模拟停止失败（进程仍在运行但无法终止）→ toast 报「停止失败」含原因 + 日志「✗ 停止失败：…」行 + 状态保持运行中；连点不并发。单测：`stop-feedback.spec.ts`（outcome=failed）。
- **T-F09-S4（AC-F09-5 未运行点击）**：任务空闲时点「停止」→ 不发请求，直接提示「当前没有运行中的进程，无需停止」。单测：`stop-feedback.spec.ts`（not-running 分支）。
- **T-F09-S5（AC-F09-6 工具契约）**：`sems_stop_command` / `sems_stop_run` 既有成功键与「无存活会话 / 无法停止进程」错误文案逐字不变（F25 守卫断言在 `SemsToolExtensionTests`）。
- **T-F09-S6（AC-F09-7 日志 404 收敛）**：运行中日志请求 404 且运行列表无该会话（宿主重启过）→ 状态收敛已结束、留痕一次、登记失效停止轮询；会话仍在则继续轮询。单测：`stop-feedback.spec.ts`（404 收敛 / 启动瞬态两组）。
- **T-F09-S7（AC-F09-8 终态退出常驻轮询，输入4 2026-11-23 补）**：任务经日志/停止收敛为已结束后，推进 ≥5 个轮询周期该命令日志请求数最多再 +1（补拉一针抓尾部留痕）且不再增长、轮询循环清空；选中已完成历史任务仅选中时拉一针，不进循环。单测：`stop-feedback.spec.ts`「终态任务必须退出常驻轮询面」两组（红→绿已验证：修复前终态选中任务每 1.2s 持续轮询）。
