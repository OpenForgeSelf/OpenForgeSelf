## 已确认（2026-11-04）

- [x] 多标签 = WT **基础**操作（新建/关闭/切换/重命名 + 隔离）；无分屏/拖拽排序/完整 profiles  
- [x] 默认 **AskWrite**；Agent 用会话级 `st_set_permission_mode`  
- [x] URL 明文密码 = 内网过渡 + 知情确认；主推 key / 交互输入 / vault  
- [x] 对外文案：「可审批的命令会话」（非完整 PTY / 非完整 WT）  

## 本轮定稿（炳宏 · 2026-11-04 · 可叫前后端）

- [x] 通用 `profile + step/run + env` 为**唯一**深链模型（SSH 只是 profile）；保留 `type`/`cmd` 兼容  
- [x] 人拼链接用重复 `step`；Agent/API 用 `run` JSON；命名不改  
- [x] `custom:<id>` **仅留协议位，本里程碑不实现**  
- [x] SSH 无密码：**先出密码框，确认后再建标签连接**（避免空连/孤儿标签）  
- [x] S5 **不做**「记住本会话」勾选；关标签即焚  
- [x] 浮层顺序：风险 ack → 交互密码 → 审批 → 审计  
- [x] 副标题「可审批的命令会话」；空态/S5 主推密钥  
- [x] `env` 中像密钥的值审计须脱敏  
- [x] **S0–S9 作为开发与测试正式验收清单**（每态截图）  
- [x] **刷新恢复本里程碑范围内**：尽量恢复标签列表、连接信息、近期输出缓冲（范围与上限见 02 / 06）
