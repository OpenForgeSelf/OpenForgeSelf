## 本轮定稿（炳宏 · 2026-11-12 · Asia/Shanghai · 可叫前后端 / 测试）

- [x] **定位**：宿主插件里的「可审批、可审计的命令会话」，不是独立终端；**不以**完整交互式 PTY / vim / htop 为验收标准
- [x] **命令输入**：提示符（`user@host:path$`）就在输出表面当前行，输入后回车即执行；**取消**下方独立命令框和主路径「运行」按钮；上/下键翻历史；Tab 补全按原型（历史 / 片段建议），不作完整壳补全验收
- [x] **权限闸**：保留 Auto / AskWrite / AskHighRisk，**默认 AskWrite**。日常只读命令回车即跑；写操作 / 高风险命令回车后先确认，批准再执行，取消则不执行
- [x] **布局**：只做标签，**不做**左右分屏；**SFTP 连入口都不露**
- [x] **右侧助手**：真正的对话（消息流 + 提示词 + 发送）；Enter 发送，Shift+Enter 换行；复用宿主 AI 网关与已配置模型，不另开账号。默认「插入到终端」（只写入提示符，不自动跑）；「批准后执行」走权限闸。对话是侧栏默认页；片段与历史为次级页签
- [x] **凭据**：SSH 配置与密钥进**宿主凭据库**；插件不存明文密码，不做「记住密码」，密码不进 URL
- [x] **SSH 新建**：无密钥时先出交互密码框，确认后再建标签；取消不建标签。断开后可重连（无密钥则再要密码）。刷新恢复标签 / 连接摘要 / 回滚输出，**永不恢复密码或密钥**
- [x] **会话形态**：本机壳（bash / zsh / sh；Windows 下 cmd / pwsh / powershell）+ SSH；可搜索配置列表；输出按命令分块
- [x] **片段**：插入到提示符，或运行（写 / 高风险走权限闸）
- [x] **展示与审计**对密钥脱敏
- [x] **视觉**：本项目金色主题；PageHead = eyebrow + 标题 + 一个主按钮；三禁；Vue 3 生产实现，不用 Element Plus 组件；加载 / 空 / 错误 / 401 / 断线必做
- [x] UI 以原型 **v0.2** 为验收基准（见 02 / 06）
