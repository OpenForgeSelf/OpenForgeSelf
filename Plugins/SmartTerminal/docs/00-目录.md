## 评审清单（请 PM 勾选）

- [ ] 多标签是否满足「像 Windows Terminal」的预期（新建 / 关闭 / 切换 / 重命名）
- [ ] URL 深链三种类型（local / ssh / wsl-ssh）是否覆盖业务场景
- [ ] **是否接受**「URL 带密码」作为过渡能力（见 05）；长期是否强制密钥
- [ ] 默认权限 AskWrite 是否合适；Agent 自动跑命令时是否要默认 Auto
- [ ] 审计字段与脱敏是否满足合规口述要求
