## 评审清单（PM 已确认 · 2026-11-04）

- [x] 多标签：对齐 Windows Terminal **基础**标签能力（新建 / 关闭 / 切换 / 重命名 + 会话隔离）；**不**做分屏、拖拽排序、完整 profiles
- [x] URL 深链三种类型（`local` / `ssh` / `wsl-ssh`）覆盖当前业务；堡垒机 / SFTP 后续再排
- [x] URL 带密码：**仅内网过渡**，非推荐默认；须知情确认 + 脱敏；长期推广 `auth=key` / 交互输入 / vault
- [x] 默认权限保持 **AskWrite**；Agent 需要自动跑时用**会话级** `st_set_permission_mode`，不改全局默认
- [x] 审计字段与脱敏口径可接受（密码不进 JSONL / 历史原文）

对外文案优先：「**可审批的命令会话**」，避免宣传成完整交互式终端 / 完整 Windows Terminal。
