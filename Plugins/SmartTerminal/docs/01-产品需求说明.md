# 01 · 产品需求说明（PRD 摘要）

## 1. 一句话

在 ForgeSelf 内提供**可审批、可审计**的本机/SSH 终端，支持 **Windows Terminal 风格多标签**，并可用 **URL 参数一键打开指定类型终端并执行命令**，供 Agent 与人工运维共用。

## 2. 目标用户

| 角色 | 诉求 |
|------|------|
| 运维 / 开发 | 在 Web 控制台开多个本地壳或 SSH 会话，少切桌面终端 |
| Agent / 自动化 | 通过工具 `st_*` 或 URL 深链拉起会话、跑只读/写入命令，卡在审批闸门 |
| 产品 / 安全 | 能说明「谁在何时跑了什么」，密码不进日志原文 |

## 3. 范围内（v1.2）

1. **多标签会话**：每个标签 = 独立 session（外壳、cwd、输出、历史、审批队列）
2. **三级权限**：Auto / AskWrite（默认）/ AskHighRisk
3. **JSONL 审计** + UI 审计抽屉（类型过滤 / 搜索）
4. **跨平台一等壳**：Linux `bash/zsh/sh`；Windows `cmd/powershell/pwsh`（+ WT profiles）；对方平台壳显示为不可用
5. **URL 深链启动**：`local` / `ssh` / `wsl-ssh`；可带初始命令列表
6. **SSH 密码自动登录（过渡）**：`sshpass -e` + 环境变量 `SSHPASS`；Windows 优先 `wsl.exe` + WSLENV 传密码
7. **CT 画廊**覆盖主要 UI 态，供视觉回归

## 4. 非目标（本版不做）

- 完整交互式 PTY / 彩色全屏 TUI（当前为命令执行 + 流式输出模型）
- 内置 SSH 密钥生成与托管 UI
- 持久化保存 URL 中的明文密码
- 远程端口转发 / SFTP 文件树

## 5. 用户故事

1. 作为开发，我可以点「+」新建 bash 标签，在标签间切换，双击改名，点 × 关闭。  
2. 作为运维，我打开  
   `/smart-terminal?st=1&type=ssh&host=10.0.0.1&user=ops&auth=sshpass&password=***`  
   系统新开 SSH 标签并尝试自动登录；地址栏密码被擦除。  
3. 作为 Agent，我 `st_create_session` + `st_run_command`；写操作在 AskWrite 下弹审批。  
4. 作为安全接口人，我在审计里只能看到脱敏命令，看不到 SSHPASS 明文。

## 6. 成功标准（验收）

- 多标签：新建 / 切换 / 关闭 / 重命名可用；各标签输出不串台  
- URL：local 带 `cmd` 能建标签并排队执行；ssh/wsl-ssh 有引导命令与脱敏审计  
- 密码：JSONL / 命令历史 / 控制台系统行无明文；URL 读入后 `history.replaceState` 擦除  
- CT：画廊含 MultiTabs、UrlLaunchLocal、UrlLaunchSshPending 等故事
