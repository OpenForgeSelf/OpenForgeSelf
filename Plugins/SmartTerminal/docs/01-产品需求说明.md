# 01 · 产品需求说明（PRD 摘要）

> 状态：已按产品经理评审收敛（2026-11-04）

## 1. 一句话

在 ForgeSelf 内提供**可审批、可审计的命令会话**（本机 / SSH），支持 **Windows Terminal 基础多标签**，并可用 **通用 URL 启动器**（`profile` + 步骤/参数/环境）打开会话并执行命令列表；SSH 只是其中一种 profile。

> 对外表述用「可审批的命令会话」，**不要**宣传为完整交互式 PTY / 完整 Windows Terminal。

## 2. 目标用户

| 角色 | 诉求 |
|------|------|
| 运维 / 开发 | 少切桌面终端，在 Web 里开多个**命令会话**标签 |
| Agent / 自动化 | `st_*` 或 URL 深链拉起会话；写操作可卡在审批闸门 |
| 产品 / 安全 | 可说明「谁在何时跑了什么」；密码不进日志原文 |

## 3. 范围内（v1.2.x）

1. **基础多标签**（对标 WT 基础操作，非完整 WT）：新建 / 关闭 / 切换 / 重命名；**每标签独立** shell、cwd、输出、历史、审批队列  
2. **三级权限**：Auto / **AskWrite（默认）** / AskHighRisk  
3. **JSONL 审计** + UI 审计抽屉（类型过滤 / 搜索）+ 密钥脱敏  
4. **跨平台一等壳**：Linux `bash/zsh/sh`；Windows `cmd/powershell/pwsh`（可探测 WT profiles）；不可用项仍列出  
5. **通用 URL 启动器**：`profile=local|ssh|wsl-ssh` + `step`/`run` + 可选 `env`/`cwd`/`title`（见 03；`custom:<id>` 协议位预留，**本里程碑不实现**）  
6. **认证**：默认交互式密码（无 URL 密码时）；`auth=key`；URL+sshpass 仅内网过渡 + 知情确认  
7. **CT 画廊**覆盖主要 UI 态（含风险 ack；交互密码态按 06 定稿）  
8. **刷新恢复**：尽量恢复标签列表、连接信息（无密码）、近期输出缓冲（上限见 02§8；对标 VS Code 终端恢复）  

## 4. 非目标（本版明确不做 · 已接受）

- 完整交互式 PTY / 彩色全屏 TUI（当前 = 命令执行 + 流式输出）  
- Windows Terminal **分屏、拖拽排序、完整 profiles 管理**  
- 内置 SSH 密钥生成与托管 UI  
- 持久化保存 URL / 交互输入中的明文密码（含刷新恢复存储）  
- **`custom:<id>` profile 实现**（协议位保留，本里程碑不做）  
- 堡垒机短票闭环、远程端口转发、**SFTP 文件树**（后续）  

## 5. 用户故事

1. 作为开发，我可以 `+` 新建 bash 标签，切换、双击改名、`×` 关闭；各标签输出不串台。  
2. 作为运维，我用 URL 打开 `profile=ssh`；**无密码则先出遮罩密码框，确认后再建标签连接**；若 URL 带密码（内网），须勾选「我已知晓风险」；地址栏密码被擦除；刷新后尽量恢复标签与近期输出（无密码）。  
3. 作为 Agent，默认 AskWrite；若某会话要自动跑，调用 **会话级** `st_set_permission_mode`，不改全局默认。  
4. 作为安全接口人，审计里只有脱敏命令，看不到 SSHPASS 明文。  

## 6. 成功标准（验收）

- 多标签基础操作可用；会话隔离  
- URL：通用 profile 启动；无密码 SSH → 交互输入；URL 密码 → ack + scrub + 脱敏  
- 默认 AskWrite；Agent 会话级改模式可用  
- CT 含 MultiTabs、UrlLaunch*、**PasswordRiskAck** 等故事  
- 刷新后可恢复标签 / 连接摘要 / 上限内输出缓冲；存储与审计无密码明文  
- 测试按 [06](./06-UI交互评审稿.md) S0–S9 + S-R 截图验收
