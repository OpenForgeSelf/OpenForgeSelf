# 02 · 交互说明

> 多标签 = Windows Terminal **基础**操作。URL = **通用启动器**（见 03）。完整 WT / 完整 PTY 不在本版。  
> **炳宏定稿（2026-11-04）**：浮层顺序、先框后标签、无「记住本会话」、刷新恢复在范围内。

## 1. 整体布局

```
┌ 标题 + 权限徽章 + 审计 ──────────────┐
│ Banner：URL 摘要 / 警告 / 错误         │
│ [标签…] [+]   ← 基础多标签            │
│ 主区：命令会话输出流                   │
│ 命令输入 / 历史（脱敏）                │
└──────────────────────────────────────┘
浮层（固定顺序，互斥优先）：
  风险 ack → 交互密码 → 审批 → 审计
```

副标题（定稿）：**「可审批的命令会话」**。

## 2. 多标签（范围不变）

新建 / 切换 / 关闭 / 重命名；会话隔离。  
**不做**：分屏、拖拽排序、完整 profiles UI。

## 3. 权限

默认 **AskWrite**。Agent 用**会话级** `st_set_permission_mode`。

## 4. 通用 URL 启动

1. 解析 LaunchSpec（`profile` + `step`/`run` + `env`/…）→ scrub 敏感 query  
2. 蓝条展示脱敏摘要（`profile=`、步数、host…）  
3. 按认证决策树（03§6）进入 ack / 交互密码 / 直接 launch  
4. 步骤仍受 AskWrite 约束  

旧参数 `type`/`cmd` 仍兼容，映射到 `profile`/`step`。  
`custom:<id>` **仅协议位，本里程碑不实现**（见 03）。

## 5. URL 明文密码 · 风险知情确认

同前：勾选「我已知晓风险」；策略 `always-ack`（默认）/ `intranet` / `disabled`。见 05。  
浮层出现时排在**最先**（先于交互密码 / 审批 / 审计）。

## 6. 交互式密码（无 URL 密码时 · 必做）

适用：`profile=ssh|wsl-ssh` 且非 `auth=key`，且请求中无 password。

| 项 | 说明（定稿） |
|----|------|
| UI | 模态 + `input type=password`（可可选显示明文开关） |
| 展示 | `user@host:port`、profile 名；**不**预填任何密码；主推密钥登录文案 |
| 时序 | **先出密码框，用户确认后再创建标签并连接**；禁止先建空标签/孤儿标签再补密 |
| 确认 | 密码仅内存交给 launch / SSHPASS；关闭模态即焚 |
| 取消 | **不**建立连接、**不**创建标签 |
| 「记住本会话」 | **不做**勾选；关标签即焚（内存密码随标签生命周期销毁） |
| 审计 | 仅 `auth=interactive` / `passwordProvided=false`；无原文 |
| 禁止 | 写回 URL、localStorage、sessionStorage、JSONL、命令历史原文 |

## 7. 审计抽屉 / 空态

审计：过滤 + 搜索，仅脱敏字段。  
**`env` 中像密钥的值必须脱敏**（键名命中 password / secret / token / key / credential 等，或值形态像密钥时，审计只留键名 + `***`）。  
空态 / S5：主推**密钥登录**；弱化 URL 密码。

## 8. 刷新恢复（炳宏新增 · 本里程碑范围内）

对标行业常见做法（如 **VS Code 终端恢复**：尽量还原标签与近期 scrollback，不持久化密钥）。浏览器刷新后**尽量恢复**，不是纯展示清空。

### 8.1 恢复范围

| 恢复项 | 是否恢复 | 说明 |
|--------|----------|------|
| 标签列表 | ✅ | 标签 id / 标题 / 顺序 / 当前激活标签 |
| 连接信息 | ✅ | `profile`、host、port、user、cwd、shell、title、`auth` 方法（key / interactive / …） |
| 近期输出缓冲 | ✅ | 每标签最近输出（system / stdout / stderr 行），受上限约束 |
| 密码 / 口令 | ❌ | **永不**写入任何持久化存储（含 sessionStorage / localStorage / IndexedDB） |
| 审批队列中的明文口令 | ❌ | 仅恢复非敏感审批元数据；口令类字段丢弃 |
| URL 中曾带入的 password | ❌ | 刷新后若仍缺密且非 key，重新走 S5（先框后标签） |

### 8.2 上限与存活（成熟默认值）

| 约束 | 默认 | 备注 |
|------|------|------|
| 每标签输出缓冲 | **最近 1000 行** 或 **约 100KB UTF-8**（先到先截） | 对标 VS Code scrollback 量级；过长则丢弃最旧行 |
| 标签数量 | 与 UI 上限一致（实现期沿用现有多标签上限；无单独抬高） | 关闭的标签不参与恢复 |
| 存储位置 | 优先 **sessionStorage**（同标签页会话） | 关浏览器标签页 / 清站点数据即失效；不写远端 |
| 会话存活 | 直至用户 **关闭该终端标签**，或浏览器存储被清除 | 关标签 = 焚毁该标签的缓冲与连接快照 |
| 后端进程 | 刷新不保证远端/本机壳进程仍存活 | UI 恢复后若连接已断，展示可重连状态；SSH 无持久密钥则再走交互密码 |

### 8.3 验收口径

刷新后可见：原标签列表与标题、连接摘要（无密码）、输出区保留上限内近期内容。  
**不得**在 DevTools Application 存储中看到 password 明文。详见 06 验收项 S-R。
