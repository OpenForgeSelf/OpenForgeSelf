# 02 · 交互说明

> 多标签范围 = Windows Terminal **基础**标签操作；完整 WT（分屏 / 拖拽排序等）不在本版。

## 1. 整体布局

```
┌ 标题 + 权限徽章 + 审计 ──────────────┐
│ （可选）URL 启动横幅 / 密码警告 / 错误 │
│ [标签1] [标签2] [标签3] [+]           │
│ （点 + 展开）新建面板：标题/壳/cwd/权限 │
│ ┌ 当前标签输出（命令会话流）─────────┐ │
│ └───────────────────────────────────┘ │
│ [命令输入........................][运行]│
│ 命令历史（脱敏）                        │
└─────────────────────────────────────────┘
  （密码深链时）风险知情确认模态
```

标签栏对标 WT **基础**体验：上沿标签、`+` 新建、`×` 关闭、双击改名。  
产品文案：「可审批的命令会话」，非完整 PTY。

## 2. 多标签（范围）

| 操作 | 手势 | 行为 |
|------|------|------|
| 新建 | `+` → 填外壳/目录 →「打开标签」 | 创建独立 session |
| 切换 | 单击标签 | 缓存上一标签输出游标，加载目标输出 |
| 关闭 | `×` / 「关闭」 | 结束进程树，session = closed |
| 重命名 | 双击标题 → 回车/失焦 | `PUT .../title` |

**本版不做**：分屏、拖拽排序、完整 Terminal profiles UI。

## 3. 权限与审批

- 顶栏徽章 = **当前标签**模式（无标签则全局默认 **AskWrite**）  
- Agent 若需自动执行：对该会话 `st_set_permission_mode`，**不改**全局默认  
- AskWrite / AskHighRisk 触发模态：「拒绝 / 批准执行」  

## 4. URL 深链进入

1. 解析 query → **立刻 scrub** 敏感参数（密码仅留在内存）  
2. 顶栏蓝条：启动摘要（密码位 `***REDACTED***`）  
3. **若含密码** → 进入「风险知情确认」（见下）通过后才 `POST /launch`  
4. 推荐深链使用 `auth=key`；密码路径仅为内网过渡  

## 5. 密码深链 · 风险知情确认（必做）

当 URL/启动请求携带密码（将走 sshpass）时：

1. 弹出模态，列出风险要点（历史 / 日志 / 分享）  
2. 用户勾选 **「我已知晓风险」** 后，「继续启动」才可点  
3. **取消**：丢弃内存中的密码，不发起 sshpass 启动（可提示改用 `auth=key`）  
4. 通过后仍保留黄条警告；密码不进审计原文  

### 策略开关（localStorage）

|键|取值|行为|
|--|--|--|
| `forge.self.smart-terminal.url-password-mode.v1` | `always-ack`（**默认**，适合公网/演示） | **每次**密码深链都要勾选确认 |
| 同上 | `intranet` | **首次**确认后写入 ack；之后同浏览器可跳过模态 |
| 同上 | `disabled` | **禁止** URL 密码；丢弃密码并提示改用密钥 |
| `forge.self.smart-terminal.url-password-risk-ack.v1` | ISO 时间戳 | `intranet` 模式下的「已知晓」持久化 |

也可在深链加 `st_url_password_mode=intranet|always-ack|disabled`（仅当次；不写盘的模式覆盖，便于内网书签）。

**排期中（未做）**：标签内交互输入一次密码；宿主 vault 注入。优先推广 `auth=key`。

## 6. 审计抽屉

右侧抽屉；类型下拉 + 关键字搜索；仅脱敏字段。

## 7. 空态

无标签：提示「点 + 新建，或通过 URL 深链启动（推荐密钥）」。
