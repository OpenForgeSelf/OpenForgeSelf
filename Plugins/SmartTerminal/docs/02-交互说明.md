# 02 · 交互说明

## 1. 整体布局

```
┌ 标题 + 权限徽章 + 审计 ──────────────┐
│ （可选）URL 启动横幅 / 密码警告 / 错误 │
│ [标签1] [标签2] [标签3] [+]           │
│ （点 + 展开）新建面板：标题/壳/cwd/权限 │
│ ┌ 当前标签输出 ─────────────────────┐ │
│ │ stdout / stderr / system          │ │
│ └───────────────────────────────────┘ │
│ [命令输入........................][运行]│
│ 命令历史（脱敏）                        │
└─────────────────────────────────────────┘
```

对标 **Windows Terminal**：标签在上，+ 新建，× 关闭，双击标题重命名。

## 2. 多标签

| 操作 | 手势 | 行为 |
|------|------|------|
| 新建 | 点 `+` → 填外壳/目录 →「打开标签」 | 创建 session，切到新标签 |
| 切换 | 单击标签 | 缓存上一标签输出游标，加载目标输出 |
| 关闭 | 标签上 `×` 或面板「关闭」 | 结束进程树，session 标 closed |
| 重命名 | 双击标题 → 回车/失焦 | `PUT .../title`；审计 `session_rename` |

每个标签独立：shell、cwd、permissionMode、chunks、commands、pending approvals。

## 3. 权限与审批

- 顶栏徽章显示**当前标签**模式（无标签则显示全局默认）  
- AskWrite / AskHighRisk 触发时弹出模态：「拒绝 / 批准执行」  
- 控制台 `system` 行同步写「等待审批 / 用户拒绝」

## 4. URL 深链进入

1. 解析 query → 立刻 **scrub** 敏感参数  
2. 顶栏蓝条：启动摘要（密码位显示 `***REDACTED***`）  
3. 若曾带密码：黄条警告（见 05）  
4. 调用 `POST /api/smart-terminal/launch` → 新建标签并执行引导  

## 5. 审计抽屉

右侧抽屉；类型下拉 + 关键字搜索；列表只展示已脱敏字段。

## 6. 空态

无标签时：控制台提示「点 + 新建，或通过 URL 深链启动」。
