# 02 · 交互说明

> 状态：**已锁定 / 原型 v0.2** · 2026-11-12（Asia/Shanghai）  
> 交互真源：[智能终端原型 v0.2](./smart-terminal-prototype.html)（标题「智能终端 · 交互原型 v0.2」）。生产实现为 `web/`（Vue 3 + 原生 HTML/CSS + 设计 token），**禁止**模板使用 Element Plus 组件（`<ElXxx>`）。  
> 原型里的「演示开关 / 模拟刷新」不属于产品界面，实现不得带上。

## 1. 设计约束

- Token：金 `#F59E0B`（gold-400），墨底 `#0B0908` / `#14110F`，玻璃卡片 blur **18** / 强层 **24**。字体：标题用宋体族（Noto Serif SC），正文 Inter / 系统黑体，等宽 JetBrains Mono（提示符、命令、输出）。
- **PageHead**：eyebrow「TERMINAL · 会话与命令」+ 标题「智能终端」+ 版本徽标（读插件版本，文档示例 `v2.0.0`；原型写 v0.2 是确认稿版本）+ **一个**主按钮「新建会话」。
- PageHead 右侧允许出现：当前权限徽章（如 `AskWrite`，不是按钮）、次按钮「命令面板」、次按钮「助手」。它们都不是第二主按钮。
- **三禁**：不用 emoji；按钮不要胶囊形（直角 / 小圆角约 4px，不是 pill）；不用蓝紫渐变。状态点可以用小圆点，类型标签可以是小圆角 tag，不用于主操作按钮。
- 必须提供加载 / 空 / 错误 / 401 / 断线 / 正常态（见 §7）。
- 长标题在侧栏配置名和标签栏单行省略，`title` 属性展示全文（原型含超长 SSH 配置名与超长标签名）。
- 副标题口径：**「可审批、可审计的命令会话」**。不得出现「完整 PTY」「完整 Windows Terminal」「完整 SSH 客户端」等夸大语。空态与 SSH 密码框主推**密钥登录**。

## 2. 信息架构与布局

```
┌ PageHead：eyebrow + 智能终端 vX    [AskWrite] [命令面板] [助手] [新建会话] ┐
├──── 左栏（配置）────┬──────── 工作区 ─────────┬──── 右侧栏（默认可开）───┤
│ 搜索配置、主机或标签  │ 标签栏：会话…  [+]      │ 对话 | 片段 | 历史        │
│ [全部][本机][SSH]    │ 断线横幅（按需）+ 重连    │ 对话：上下文 + 消息流      │
│ 配置列表              │ 窗格头：user@host / 壳   │      + 提示词 + 发送      │
│  · 名称（过长省略）   │ 输出块（命令 + 输出）     │ 片段 / 历史为次级页       │
│  · 类型 · 摘要        │ user@host:path$ [输入_]  │                          │
└──────────────────────┴─────────────────────────┴──────────────────────────┘
浮层（互斥，优先顺序）：交互密码 → 审批确认 → 命令面板 / 新建会话 → 审计（若打开）
```

底栏沿用宿主状态栏；插件可在底栏或 PageHead 附近展示会话数与当前权限，不另做一套壳。

- 默认：右侧栏打开，且停在「对话」。点 PageHead「助手」切换右侧栏显隐；重新打开时回到「对话」。
- **没有**左右分屏入口，工作区同一时间只展示当前标签的一个窗格。
- **没有** SFTP / 文件树入口。
- 没有底部独立命令框，没有主路径「运行」按钮。

## 3. 左侧配置

- 搜索框占位：「搜索配置、主机或标签」，按名称或摘要过滤。无匹配时局部空态「没有匹配的配置」，不占用整页空态。
- 类型筛选：全部 / 本机 / SSH，testid `st-filter-all` / `st-filter-local` / `st-filter-ssh`。
- 列表项展示：状态点（已打开且已连接为绿，已打开但断开为红，未打开无色）、名称、类型标签（本机 / SSH）、摘要（如 `deploy@10.2.8.21:22 · 密钥`）。
- 点击已打开的配置：切到对应标签并聚焦提示符。
- 点击未打开的本机或密钥 SSH 配置：直接创建标签并连接。
- 点击「交互密码」类 SSH：先出密码框，确认后再建标签；取消不建标签。

## 4. 标签与工作区

- 标签栏：已打开会话（状态点 + 标题 + 关闭 ×）+ 末尾「+」新建。单击切换；关闭后焦点落到相邻标签；全部关闭则进入整页空态。
- 窗格头：本机显示 `shell · cwd`，SSH 显示 `user@host`；右侧「已连接」或「已断开」。
- **断线**：当前标签断开时出现横幅「会话已断开，输出仍保留。重新连接不会恢复密码。」+「重新连接」。提示符禁用，占位「会话未连接，请先重新连接」。无密钥 SSH 重连再次走密码框；取消则保持断开、不丢已有输出。
- 输出按命令分块：块头为 `$ command`（系统块如 `connected` / `reconnect` 不带 `$`）+ 退出码与时间；失败块可区分。点选块作为助手上下文（同时打开右侧栏）。系统选中文本即可复制，不单独做复制按钮验收。
- **提示符行**：`user@host:path$` + 当前输入。点击输出表面空白处或提示符行，焦点回到输入。未在输入框内按可打印字符时，应把焦点带回提示符并写入（与原型一致，避免「不知道该点哪里才能输入」）。
- 回车：提交当前行（见 §5）。空行回车不发送。
- 上 / 下键：翻本会话命令历史；翻出边界后可回到尚未提交的草稿。
- Tab：若有与当前输入匹配的历史 / 片段建议，补全第一条（原型行为）。建议列表最多约 6 条。这不是完整 bash / powershell 补全，失败不挡主路径验收。
- `clear`：清空当前标签已展示的输出块，历史仍保留。
- 同一会话同时只执行一条命令；运行中提示符禁用，本里程碑不以 Ctrl+C 中断为验收项。

## 5. 命令提交与审批

1. 用户在提示符回车，或从片段「运行」、助手「批准后执行」提交同一条命令。
2. 分类（只读 / 写 / 高风险 / 硬拒绝）按当前会话权限模式决定：
   - **Auto**：除硬拒绝外直接执行
   - **AskWrite**（默认）：只读直接执行；写与高风险先确认
   - **AskHighRisk**：只读与写直接执行；仅高风险先确认
   - 硬拒绝：不执行，给出可读原因（可用系统块或 toast，不得静默吞掉）
3. 确认框标题区分「ASKWRITE · 写操作确认」与「ASKHIGHRISK · 高风险确认」；展示脱敏后的命令原文；说明默认闸为 AskWrite；「取消」关闭且**不执行**（草稿可留在提示符）；「批准并运行」才执行。
4. 执行后追加一个命令块，历史写入该行，提示符清空并重新聚焦。
5. 浮层顺序：若同时需要密码与审批，先密码、后审批。危险确认必须用模态，不得只用一秒消失的 toast。

权限徽章展示当前模式（随当前标签）。切换入口为次级（点击徽章或命令面板），不占用主按钮。默认模式始终是 AskWrite。

## 6. 右侧栏

### 6.1 对话（默认）

- 顶部上下文条：标明「复用宿主已有设施，走宿主 AI 网关与已配置模型，不另开账号」；展示当前会话名，以及点选块或最近一条非系统命令作上下文。
- 消息流：用户泡与助手泡。助手若给出建议命令，在泡内展示命令，并提供「插入到终端」「批准后执行」。
- **插入到终端**：只把命令写入当前提示符草稿，**不自动执行**，toast 提示「已插入到终端提示符，不会自动执行」，焦点回到提示符。未连接时拒绝并提示。
- **批准后执行**：提交到与回车相同的权限闸；需要确认则弹确认框。
- 底部：多行提示词 +「发送」。Enter 发送，Shift+Enter 换行。发送中输入框与按钮禁用，线程中出现「正在调用宿主模型…」。
- 无打开会话时发送：提示「还没有打开的会话」，不虚构回复。
- 宿主模型不可用：在对话区给出可读错误，不把整个终端打挂。

### 6.2 片段

- 列表项：名称、命令、次按钮「插入到终端」、主按钮「运行」。
- 「运行」走 §5 同一套闸，不是绕过审批的快捷方式。

### 6.3 历史

- 当前会话已执行命令（可与常见只读示例合并展示，实现以本会话历史为准）。
- 可搜索；点击一项即「插入到终端」，不自动执行。
- 无历史：局部空态「还没有命令历史」。

## 7. 新建会话、密码框、命令面板

### 7.1 新建会话

PageHead 主按钮、空态主按钮、标签栏「+」、命令面板均可打开。模态内切换「本机壳 / SSH」，**不得出现 SFTP 选项**。

- 本机：外壳（不可用项 disabled）、起始目录、可选标签标题（默认用外壳名）。确认后立即建标签并连接。
- SSH：主机、端口（默认 22）、用户、认证（「私钥（推荐，存宿主凭据库）」/「交互式密码」）、可选标题（默认 `user@host`）。文案写明：密钥由宿主凭据库保管；不会提供「记住密码」；交互式密码确认后再创建标签，取消不建标签。**选私钥时必须指定已有凭据句柄或本机私钥路径**（原型未单独画出选择器，实现须补上；缺材料则不能创建，见 03 `credential_required`）。不允许在该表单里填写登录密码并勾选保存。
- 缺主机或用户时留在窗内提示，不创建。
- 选交互式密码：关闭新建窗，再出密码框（先框后标签）。

### 7.2 交互式密码

- 遮罩 + `input type=password`（可可选「显示密码」，默认隐藏）。展示 `user@host:port`。**不预填**任何密码。无「记住密码 / 记住本会话」勾选。
- 确认后密码仅内存交给连接，关闭模态即焚。
- 取消：**不**建立连接、**不**创建标签（重连场景则保持原标签断开）。
- 空密码点连接：提示「请输入密码后再连接」，留在窗内。
- 禁止：写回 URL、localStorage、sessionStorage、IndexedDB、JSONL、命令历史、审计原文、GET 查询。

### 7.3 命令面板（P1，原型已有）

Ctrl / Cmd + K，或 Ctrl / Cmd + Shift + P，或 PageHead「命令面板」。可搜索「新建本机会话 / 新建 SSH 会话 / 打开助手对话 / 打开命令历史 / 打开片段 / 打开某配置 / 切换到某会话」。Enter 执行，Esc 关闭。不是主输入路径。

## 8. 刷新恢复（S-R）

对标常见做法（如 VS Code 终端恢复）：尽量还原标签与近期 scrollback，**不**持久化密钥。存储优先 **sessionStorage**，键名必须是 **`st:ui`**。

建议结构（实现可增字段，但不得含密钥）：

```json
{
  "activeId": "s-1",
  "railOpen": true,
  "railTab": "ai",
  "tabs": [
    {
      "id": "s-1",
      "title": "本机开发",
      "profileId": "p-local-bash",
      "kind": "local",
      "shell": "bash",
      "cwd": "~/work/forgeself",
      "status": "connected",
      "host": null,
      "user": null,
      "auth": null,
      "blocks": []
    }
  ]
}
```

| 恢复项 | 是否恢复 |
|--------|----------|
| 标签列表、标题、顺序、当前激活标签 | 是 |
| 连接摘要：`kind` / profile / host / port / user / cwd / shell / `auth` 方法 | 是 |
| 近期输出块 | 是，每标签最近 **1000 行**或约 **100KB UTF-8**（先到先截） |
| 右侧栏是否打开、当前次级页签 | 是（打开时仍默认可回到对话） |
| 提示符未提交草稿、助手未发送草稿 | 否（安全起见不强制恢复） |
| 密码、私钥、口令、SSHPASS、审批中的明文口令 | **永不**写入此键或任何持久化存储 |
| 后端壳进程仍然存活 | 不保证。若已断，UI 恢复为断开并保留输出，由用户重连；无密钥 SSH 再走密码框 |

恢复成功后出现 toast，`data-testid="st-restored"`，文案：「已恢复标签与近期输出，未恢复任何密码或密钥」。

## 9. 状态

| 态 | 表现 | testid |
|----|------|--------|
| 正常 | 左右栏有数据，可开会话、在提示符回车、与助手对话 | — |
| 加载 | 工作区「正在取回会话与配置…」 | `st-state-loading` |
| 空 | 「炉火已起，还没有打开任何会话」+ 引导从左侧选择或新建 | `st-state-empty` |
| 错误 | 「会话列表加载失败」+ 失败请求摘要 + 重试 | `st-state-error` |
| 401 | 「登录已过期，暂时无法打开终端会话」+「重新登录」 | `st-state-401`、`st-relogin` |
| 断线 | 横幅 + 重连；提示符禁用；输出保留 | `st-disconnected-banner`、`st-reconnect` |

401 不得假装已有会话数据。「重新登录」走宿主登录，插件不自建账号。

错误态展示的请求路径用真实前缀 `/api/smart-terminal/sessions`（不要再写原型里的 `/api/plugins/smart-terminal/sessions`）。

配置筛选无结果、某会话无历史、助手尚无消息，属于局部空态，不占用整页 `st-state-empty`。加载 / 空 / 错误 / 401 时不展示右侧栏。
