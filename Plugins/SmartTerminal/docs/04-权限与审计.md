# 04 · 权限与审计

## 1. 三级权限

| 模式 | 行为 |
|------|------|
| **Auto** | 除硬 denylist 外自动执行 |
| **AskWrite**（默认） | 只读自动；写/副作用/高危询问；硬拒绝仍拦 |
| **AskHighRisk** | 多数自动；仅高危询问；硬拒绝仍拦 |

规则文件：插件数据目录 `permission-rules.json`（可热改）。

与宿主工具级 PermissionProfile 互补：本插件管**会话内命令**；全局工具策略仍走宿主配置。

## 2. URL / Launch 引导命令

SSH 自动登录引导走 `launch:bootstrap`：

- 记入审计 `kind=launch_connect`，命令为**已脱敏**标签  
- 不二次走「询问」闸门（否则无法完成自动登录）  
- 引导之后的 `cmd` 列表仍走正常 `ProposeOrRun` 分类

## 3. JSONL 审计字段

常见 `kind`：`session_create` / `session_rename` / `session_close` / `launch` / `launch_connect` / `classify` / `approval_*` / `command_result` / `permission_mode`。

一律只存 `commandRedacted`；`SSHPASS`、`password=`、Bearer 等由 `SecretRedactor` 处理。

## 4. Agent 工具

`st_list_shells` / `st_create_session` / `st_run_command` / `st_get_output` / `st_list_sessions` / `st_set_permission_mode` / `st_query_audit` / `st_resolve_approval`  
（launch 以 HTTP 为主；如需工具化可后续加 `st_launch`）
