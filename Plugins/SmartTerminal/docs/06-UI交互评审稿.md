## 1. 屏幕 / 状态清单

| ID | 状态 | 用户可见要点 | 验收要点（截图） |
|----|------|--------------|------------------|
| S0 | **空态** | 「炉火已起，还没有打开任何会话」+ 从左侧选择或新建；主推密钥文案可在空态或新建 SSH 中出现 | `st-state-empty`；主按钮「新建会话」可点；无底部命令框、无「运行」主按钮、无分屏 / SFTP 入口 |
| S1 | **正常 · 提示符** | 左配置 + 标签 + 输出块 + 当前行 `user@host:path$` 可输入；回车后出现新块，无独立输入条 | `st-prompt-line` / `st-prompt-ps1` / `st-command-input`；至少一条只读命令回车即跑；上键能翻出历史 |
| S2 | **多标签 / 长标题** | ≥2 个标签，切换输出不串台；× 关闭；长标题在标签与侧栏单行省略 | `st-tab-bar` / `st-tab-*`；长标题有 `title`；关闭后焦点落到邻标签 |
| S3 | **新建本机会话** | 本机壳 / 起始目录 / 可选标题；不可用壳 disabled | `st-new-session` / `st-new-session-submit`；打开后新标签已连接并聚焦提示符 |
| S4 | **SSH 密钥连接** | 认证选私钥；无密码框即可建标签；文案说明密钥在宿主凭据库 | 确认前可填主机用户；成功横幅/块含连接摘要，无密码 |
| S5 | **交互式密码（先框后标签）** | 遮罩密码框；显示 `user@host:port`；不预填；无「记住密码」；主推密钥 | `st-ssh-password` / `st-ssh-connect` / `st-ssh-cancel`。确认前标签栏**不得**出现新标签；取消后仍无该标签；历史与存储无明文 |
| S6 | **写操作审批（AskWrite）** | 提示符回车或片段 / 助手「批准后执行」触发；展示脱敏命令；取消不执行 | `st-approval-cmd` / `st-approval-confirm` / `st-approval-cancel`。取消后无对应成功块；批准后才有输出块 |
| S7 | **高风险审批** | 标题为 AskHighRisk；取消不执行 | 与 S6 同类钩子；文案区分高风险 |
| S8 | **断线与重连** | 横幅「输出仍保留。重新连接不会恢复密码。」+ 重连；提示符禁用 | `st-disconnected-banner` / `st-reconnect`。无密钥重连再次走 S5；取消保持断开且块还在 |
| S9 | **右侧助手对话** | 默认「对话」；上下文条写明复用宿主模型；Enter 发送、Shift+Enter 换行；建议命令可「插入到终端」（不自动跑）或「批准后执行」（走闸） | `st-side-panel` / `st-rail-ai` / `st-chat-thread` / `st-chat-input` / `st-chat-send` / `st-ai-insert` / `st-ai-run`。插入后提示符出现命令且未多出执行块；写命令的批准后执行仍出 S6 |
| S10 | **片段与历史** | 次级页签；插入不执行；运行走闸 | `st-rail-snippets` / `st-rail-history` / `st-snippet-*` |
| S11 | **加载 / 错误 / 401** | 见 02 §9 | `st-state-loading` / `st-state-error` / `st-state-401` / `st-relogin`；错误摘要路径为 `/api/smart-terminal/sessions` |
| S-R | **刷新恢复** | 刷新后标签、连接摘要、近期输出仍在；无密码 | toast `st-restored`；键必须是 `st:ui`；Application 存储无密码 / 私钥明文；缺密 SSH 若需重连再走 S5 |

夹具建议：至少一条已连接本机会话、一条密钥 SSH、一条交互密码 SSH（可先连后断）、一条长标题标签、一条失败命令块（非 0 退出码）、一条可触发 AskWrite 的命令（如 `sudo nginx -s reload`）和一条高风险演示命令。生产数据不得使用真实生产口令。

## 2. 设计走查（每张截图顺带看）

- PageHead：eyebrow「TERMINAL · 会话与命令」+ 标题「智能终端」+ 版本 + **一个**主按钮（新建会话）。命令面板、助手、权限徽章都不是第二主按钮。
- 无 emoji、无胶囊主按钮、无蓝紫渐变。
- 玻璃卡片、墨底金点，提示符与输出使用等宽字体，与原型同一套 token。
- 界面没有底部独立命令框，没有作为主路径的「运行」按钮，没有分屏、没有 SFTP。
- 按钮禁用态可见（未连接的提示符、发送中的对话输入、不可用外壳）。
- 空态与 S5 明确推荐密钥登录。S5 无「记住密码」。

## 6. 仍开放、但不挡契约与本清单的问题

下列不影响按 v0.2 验收主路径，实现可按括号中的默认：

1. 命令面板、Tab 建议补全：原型已有，作 P1；缺省不挡 S1。
2. 标签重命名、把临时 SSH 另存为配置：P1；PATCH `/sessions/{id}` 与 POST `/profiles` 已在 03 预留。
3. 审计抽屉的具体位置：次级入口即可，有 `GET /audit` 和脱敏数据就满足安全验收。
4. 助手流式输出、Ctrl+C 中断：P2，不挡 S9 / S1。
5. 旧 URL 深链与 `st_*`：**建议沿用，待实现时与 03 对齐**，不列入本轮 S0–S-R 必截图项。
6. `wsl-ssh`：本里程碑不做入口。
7. 新建 SSH 选「私钥」时的密钥选择器：原型只有认证下拉。实现默认须能选择已导入的宿主凭据句柄或填写本机 `identityFile`；否则走 `credential_required`，不挡 S4（可用已保存的密钥配置验收）。

除此之外，提示符回车、先框后标签、AskWrite 默认、助手插入不自动执行、无分屏无 SFTP、刷新不恢复密码、testid 与恢复键，均已锁定，不再视为开放问题。
