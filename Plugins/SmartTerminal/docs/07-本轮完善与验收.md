# 07 · 本轮完善与验收（已锁定）

> 日期：2026-11-16（Asia/Shanghai）  
> 在已锁定的原型 v0.2 与 2026-11-15 补充锁定之上，明确本轮完善口径与宿主验收项。不改变提示符回车、AskWrite 默认、只做标签、无分屏、无 SFTP、凭据进宿主库、助手复用宿主模型。  
> 产品口径仍以 01–06 为准；本文件补齐本轮必验项与测试方法。

## 1. 本轮要达到的产品状态

智能终端应是可在生产宿主中使用的命令会话插件：本机与 SSH 都可开多个标签，提示符回车执行，写操作先确认，右侧助手能针对当前会话给出建议，并在用户确认后执行。每一项主路径功能都要在真实宿主上验证，并留下截图证据。

本轮不扩大非目标：不做分屏，SFTP 连入口都不露，不另开 AI 账号，不以完整交互式 PTY 为验收标准。

## 2. 本轮完善项（产品表述）

下列均已在 01 / 02 / 06 中出现，本轮按「必须在宿主上可演示、可截图」收口，不再停留在画廊夹具。

| 项 | 说明 |
|----|------|
| 多标签会话 | 可同时打开多个本机或 SSH 会话；切换时输出、cwd、历史不串台；关闭后焦点落到邻标签 |
| 命令分块 | 提示符在输出表面当前行，回车后形成命令块；无底部独立命令框，无主路径「运行」按钮 |
| 目录跟随 | 在已连接会话执行 `cd` 到另一存在目录后，提示符与窗格头 / 连接摘要必须显示新 cwd（S-CWD） |
| 默认起始目录 | 新建本机使用默认起始目录（空、「用户主目录」或 `~`）时，进入当前用户真实主目录，不得把 `~` 拼到程序 / 进程目录（S-HOME） |
| 非法路径拒建 | 不存在或无法解析的起始目录，确认后在启动前明确报错，不得出现新标签（S-PATH） |
| 助手插入 | 「插入到终端」只把建议命令写入提示符，不自动执行 |
| 助手批准后执行 | 「批准后执行」走与提示符回车相同的权限闸；取消不执行，批准后出现命令块 |
| 片段与历史 | 插入不执行，运行走闸 |
| 断线与刷新 | 断线横幅与重连；刷新恢复标签、连接摘要与近期输出，永不恢复密码 |

## 3. 助手验收的测试方法（S9-RUN）

为稳定验证「插入」与「批准后执行」，使用可预期的模拟回复：在模型 / 模拟服务中配置关键词，发送该词即返回事先写好的命令建议。

验收步骤：

1. 配置一条关键词到固定建议命令（例如关键词 `demo-ls` 返回 `ls -la`，以及一条会触发 AskWrite 的写命令建议）。
2. 在已连接的本机会话打开右侧对话，发送关键词，助手给出预期建议。
3. 「插入到终端」：提示符出现该命令，且未多出执行块。
4. 「批准后执行」一条写命令：先取消，确认无对应成功块；再批准，出现输出块，过程走 AskWrite。

优先使用宿主已提供的关键词模拟回复。若入口名称与配置方式以当前宿主界面为准；也可用 OpenAI 兼容的本地 mock 上游达到同样效果。不得用真实外部模型的随机输出作为本项唯一证据。
