# 智能终端原型 v0.2

日期：2026-11-12（Asia/Shanghai）。这是确认稿变更，不是实现提交。

## 已确认的首版范围

- 宿主插件里的命令会话，不是独立终端。
- 产品定义：可审批、可审计的命令会话；不以完整交互式 PTY / vim / htop 为验收标准。
- 只做标签，首版不做左右分屏（原型已撤掉分屏入口）。
- 权限闸保留 Auto / AskWrite / AskHighRisk，默认 AskWrite。
- SFTP 首版连入口都不露。
- SSH 配置与密钥进宿主凭据库，插件不存明文密码。

## 相对 v0.1 的两处交互调整

1. **命令输入按真正的终端来做。** 去掉下方独立命令框和「运行」按钮。提示符（`user@host:path$`）就在输出表面的当前行，输入后回车即执行；输出仍可按命令分块。上/下键翻历史。日常命令回车直接跑；写操作或高风险命令回车后先弹出确认，批准后再执行。
2. **右侧 AI 做成真正的助手对话。** 默认打开「对话」：消息流 + 底部提示词输入 +「发送」。Enter 发送，Shift+Enter 换行。复用宿主已有的 AI 网关与模型，不另开账号。可用当前会话 / 最近命令块作上下文。提供「插入到终端」（只写入提示符，不自动跑）和「批准后执行」（需要时走 AskWrite / AskHighRisk）。片段与历史仍在侧栏次级页签。
