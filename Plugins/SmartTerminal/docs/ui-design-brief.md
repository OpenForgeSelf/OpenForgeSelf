# 智能终端 · 交互说明（给设计师）

## 功能

- 左侧：新建会话（标题 / 外壳 / 工作目录 / 权限模式）、会话列表  
- 右侧：实时输出控制台、命令输入、命令历史（可重跑）  
- 权限徽章：Auto / AskWrite / AskHighRisk  
- 审批弹窗：展示脱敏命令、风险、规则；批准 / 拒绝  
- 审计抽屉：JSONL 事件流过滤浏览  

## 五态

| 态 | 表现 |
|----|------|
| 加载 | 版本徽标「加载中」，控制台「等待输出」 |
| 空 | 无会话提示「点新建」；无输出提示 |
| 出错 | 顶栏红色横幅；401 单独文案 |
| 无权限 | 401 横幅，不假装有数据 |
| 正常 | 会话可选、命令可跑、审批可弹 |

## 用户旅程

1. 选外壳与权限 → 新建会话  
2. 输入命令 → 只读直接跑 / 写或高危弹审批  
3. 批准后看输出；打开审计回看；历史一键重跑
