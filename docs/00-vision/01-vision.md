# 01-vision — 项目愿景

> 状态：草稿（待用户确认细化）
> 最后更新：2026-08-06

## 一句话愿景

**铸己匣（OpenForgeSelf）：一个本地优先、可自我演进、插件化的个人 AI 智能体工作台——把"铸造自己的 AI 助手"变成每个普通用户都能做的事。**

## 阐述

- **本地优先**：数据与模型默认留在用户自己机器上（如 LM Studio 本地模型），不依赖云端绑定，隐私可控；
- **可自我演进**：功能通过插件体系持续生长，Agent 遵循 Loop Engineering 闭环（Goal → Context → Plan → Execute → Verify → Iterate）自主推进，人在回路外；
- **插件化**：一切能力（AI 提供者、待办、快捷链接、记忆、工作流、调度器、MCP、脚本）都是可插拔模块，按 `plugin.json` 注册，随需组合；
- **普通用户可及**：不是开发者专属工具箱，而是有设计稿驱动的、配置即可用的桌面应用（Vue 前端 + 托盘常驻）。

## 我们不是

- 不是云端 SaaS 平台（不做强制账号/订阅体系）；
- 不是通用聊天框（有结构化的功能面板与工作流编排）；
- 不是纯玩具 demo（真实后端、真实认证、e2e 不 mock 的铁律保证可用性）。
