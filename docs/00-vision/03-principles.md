# 03-principles — 项目原则（什么做 / 什么不做）

> 状态：生效（2026-11-02 增补 MAF 一等与插件简化）
> 最后更新：2026-11-02
> 本文件是**功能演进的裁判规则**：任何新功能提案对照此表逐条检查，违反任一条即否决或要求调整。

## 必须做（原则 → 现状依据）

| # | 原则 | 现状依据 |
|---|------|----------|
| P1 | **真实可用优先**：功能必须能真实跑通（真实后端 + 真实认证），不允许 mock 过关 | AGENTS.md §2.3；e2e 铁律 |
| P2 | **可验证性优先**：任务完成由自动化检查判定（构建/测试/lint/e2e），不靠"看起来对了" | AGENTS.md 核心原则 1 |
| P3 | **本地优先**：数据与模型默认在本地，不强制云端 | `01-vision.md`；LM Studio 本地接入 |
| P4 | **插件化扩展**：新能力走 `Plugins/` + `plugin.json` 注册，不硬编码进主程序 | AGENTS.md §2.3；`plugin-design-boundary.md` |
| P5 | **TDD 优先**：新逻辑先写测试定义预期，再写实现 | AGENTS.md §4.2 |
| P6 | **密钥必须加密落库**：敏感凭据 AES-256-CBC 加密，响应只出掩码 | `docs/02-features/100-secret-encryption.md` |
| P7 | **样式走统一 token**：Element Plus `--el-*` + Tailwind 布局原语，组件禁止显式导入 | AGENTS.md §4.2；DESIGN.md |
| P8 | **人在回路外**：Agent 自主闭环执行，仅在超出能力时升级给人（高风险工具走审批） | AGENTS.md 核心原则 3；ADR-006 |
| P9 | **执行中枢 MAF 一等**：任务执行以 MAF Runtime 组织；用户可见插件名是「智能体」。能力建在 MAF + ToolRegistry + Cordis 上 | `01-vision.md`；ADR-005/006 |
| P10 | **插件简化**：能力进插件；内核/MAF 只做编排与安全接缝；禁止平行执行引擎 | `maf-centric-architecture.md` |

## 不做（红线）

| # | 不做 | 原因 |
|---|------|------|
| N1 | 不做强制账号/订阅的云端 SaaS 化 | 违背本地优先愿景 |
| N2 | 不 mock 关键路径换取测试通过 | 违背 P1/P2，掩盖真实缺陷 |
| N3 | 不删除测试来"通过"验证 | AGENTS.md §5 判定规则 |
| N4 | 不绕过加密存明文密钥 | 违背 P6 |
| N5 | 不顺手重构无关代码 | 范围控制（AGENTS.md §1.3） |
| N6 | 不做云端计算机 / 团队企业管理套件 | `01-vision.md` 红线 |
| N7 | 不另起 LocalBot / 平行 Agent Runtime | ADR-005/006；not-taken 050 |

## 冲突处理

- 原则冲突时：P1（真实可用）> P2（可验证）> P9（MAF 一等）> 其余；仍无法裁决 → 升级给人决策并记录到 `07-decisions/`。
