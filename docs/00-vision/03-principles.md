# 03-principles — 项目原则（什么做 / 什么不做）

> 状态：草稿（从现有约定提炼，待用户确认）
> 最后更新：2026-08-06
> 本文件是**功能演进的裁判规则**：任何新功能提案对照此表逐条检查，违反任一条即否决或要求调整。

## 必须做（原则 → 现状依据）

| # | 原则 | 现状依据 |
|---|------|----------|
| P1 | **真实可用优先**：功能必须能真实跑通（真实后端 + 真实认证），不允许 mock 过关 | AGENTS.md §2.3；e2e 铁律（memory） |
| P2 | **可验证性优先**：任务完成由自动化检查判定（构建/测试/lint/e2e），不靠"看起来对了" | AGENTS.md 核心原则 1 |
| P3 | **本地优先**：数据与模型默认在本地，不强制云端 | vision；LM Studio 本地接入 |
| P4 | **插件化扩展**：新能力走 `Plugins/` + `plugin.json` 注册，不硬编码进主程序 | AGENTS.md §2.3 |
| P5 | **TDD 优先**：新逻辑先写测试定义预期，再写实现 | AGENTS.md §4.2 |
| P6 | **密钥必须加密落库**：敏感凭据 AES-256-CBC 加密，响应只出掩码 | `docs/02-features/100-secret-encryption.md` |
| P7 | **样式走统一 token**：Element Plus `--el-*` + Tailwind 布局原语，组件禁止显式导入 | AGENTS.md §4.2；设计稿工作流 |
| P8 | **人在回路外**：Agent 自主闭环执行，仅在超出能力时升级给人 | AGENTS.md 核心原则 3 |

## 不做（红线）

| # | 不做 | 原因 |
|---|------|------|
| N1 | 不做强制账号/订阅的云端 SaaS 化 | 违背本地优先愿景 |
| N2 | 不 mock 关键路径换取测试通过 | 违背 P1/P2，掩盖真实缺陷 |
| N3 | 不删除测试来"通过"验证 | AGENTS.md §5 判定规则 |
| N4 | 不绕过加密存明文密钥 | 违背 P6 |
| N5 | 不顺手重构无关代码 | 范围控制（AGENTS.md §1.3） |

## 冲突处理

- 原则冲突时：P1（真实可用）> P2（可验证）> 其余；仍无法裁决 → 升级给人决策并记录到 `06-decisions/`。
