# 04-direction — 演进方向（MAF-centric）

> 状态：生效（2026-11-02）
> 最后更新：2026-11-02
> 本文件回答：功能往哪个方向演进、优先级怎么定。是 `15-roadmap/` 与 `02-goals.md` 的上游输入。

## 演进方向（按主题）

### D1 · MAF 深度（执行中枢做透）

优先于新插件广度：把 MAF Runtime + ToolRegistry 审批/取消/轨迹做成可依赖的底座（对齐 `02-goals.md` **P0**）。

### D2 · 本机能力广度（插件扩展）

在 P0 达标后，按插件简化思想扩展：文件/终端加固、Skills、Scheduler→Run、Browser、Memory（**P1–P4**）。新增能力一律 `Plugins/` + `plugin.json`，**禁止**在宿主或 AIAgent 内再堆平行执行引擎。

### D3 · 自治与自我演进

向「提案 → 路线图 → MAF Run 实现 → 验证」演进；依赖愿景文档完备 + 验证门禁自动化。仍以个人本机为界，不做团队/云端计算机。

## 优先级决策准则（新功能提案评审用）

1. **是否符合 `03-principles.md`？**（违反任一条 → 否决/调整）
2. **是否服务于 `01-vision.md`（智能体入口 · MAF 执行中枢 · 本机个人 Agent）？**（与愿景无关 → 低优先）
3. **是否对齐 `02-goals.md` 当前阶段（P0→P4）？**（对齐 → 排进 roadmap；不对齐 → backlog）
4. **是否落在 MAF + ToolRegistry + Cordis？**（另起 Runtime / LocalBot → 否决，见 ADR-006）
5. **成本收益**：同优先级下先做对 P0 安全底座贡献大的。

## 明确不做（当前与中期）

- 云端同步/多端登录作为主产品（与本机优先冲突，除非用户明确改愿景）；
- 云端计算机、团队/企业管理套件；
- 平行 LocalBot Runtime；
- 桌面端整体重写（保持 Vue + 托盘，除非另有架构 ADR）；
- 为旧 FreeLoop/ReactLoop 命名做长期兼容层（绿场：文档与对外文案先切，契约重命名按批次删除旧旁路）。
