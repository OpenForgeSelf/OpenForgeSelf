# 00-vision — 项目北极星（愿景/目标/原则/方向）

> 本目录是 OpenForgeSelf（铸己匣）的**最高层元文档**：回答"为什么存在、要去哪、什么做/什么不做"。
> 自动演进功能时的裁判依据在此——新功能提案先对照本层评审，符合才进入 `15-roadmap/`，再落地到 `02-features/`。

## 文档导航（按阅读顺序，序号即阅读序）

| 序号 | 文件 | 回答的问题 | 读者 |
|------|------|-----------|------|
| 01 | `01-vision.md` | 这个项目想成为什么（一句话愿景 + 阐述） | 所有人 |
| 02 | `02-goals.md` | 分阶段目标是什么，如何衡量 | 所有人 |
| 03 | `03-principles.md` | 什么做 / 什么不做（功能演进裁判规则） | 功能决策者、Agent |
| 04 | `04-direction.md` | 功能往哪个方向演进、优先级怎么定 | 路线图制定者、Agent |

## 使用规则

1. **新增/改动本目录文档**：须与项目实际状态一致，不得虚构目标；
2. **功能提案评审**：按 `03-principles.md` 逐条对照，记录通过/否决理由到 `15-roadmap/`；
3. **定期回顾**：目标达成或方向调整时更新 `02-goals.md`，并在 `17-changelog/` 记录。

## 与其他目录的关系

```
00-vision（战略：为什么、去哪）
   ↓ 决定
15-roadmap（执行：下一步做什么）
   ↓ 落地
02-features（结果：做成了什么）
```
