# Case：2026-11-02 智能体页空白与旧名

> 规则见 [PC-021](../problem-classes/PC-021-agent-entry-blank-or-old-name.md)。

## 1 现象

本地开发栈 `http://localhost:7399/ai-agent`。顶栏按钮文案是「AI Agent」。`.main-content` 的 `innerHTML` 是空注释，没有「插件界面加载失败」。当时浏览器没有访问密钥，清单请求 401。插件 `web/dist` 也不存在。

## 2 复现红灯

浏览器实测（2026-11-02 17:46 前后）：清单 401，主区域空注释，顶栏「AI Agent」。补上兜底路由后、还没排除冲突检测时，带上密钥重新打开，主区域变成「这个页面没有加载出来」，路径仍是 `/ai-agent`。这是修冲突检测之前的页面状态。

## 3 根因（5 Whys + 第 6 问）

1. 为什么主区域是空的？→ 没有路由组件。
2. 为什么没有？→ 清单 401，动态路由没注册；界面产物也没构建。
3. 为什么顶栏不是「智能体」？→ `tabs.ts` 的种子标签写死旧名，已有路径不会被后来的打开动作改名。
4. 为什么兜底页出现后插件仍不在 `/ai-agent`？→ `isPathTaken` 把 `/:pathMatch(.*)*` 当成占用了所有单段路径。
5. 为什么改名时没改到标签？→ 功能表和 `plugin.json` 改了，宿主壳上的种子字符串没进同一处。
- **第 6 问：** 没有一条测试锁定默认标签文案，也没有一条测试锁定「兜底路由不算路径冲突」。

## 4 同类扫查命中表

| 位置 | 同根因？ | 处置 |
|------|----------|------|
| `tabs.ts` 种子标签 | 是 | 改为「智能体」 |
| `App.vue` 打开页面传入的标题 | 是 | 改为「智能体」 |
| `SettingsView.vue` 分类名与眉题 | 是 | 改为「智能体」 |
| `ChatView.vue` 标题 | 是 | 改为「智能体」 |
| `GeneralPanel.vue` / `AiAgentPanel.vue` 说明句 | 是 | 改为「智能体」 |
| `isPathTaken` 对兜底路由 | 是 | 跳过 `route-missing` 与 `(.*)` |
| `Plugins/Home`、`Plugins/TodoTracker` 等包内仍写「AI Agent」 | 同名、另一包 | 记入 TODO「宿主外仍有「AI Agent」可见文案」；本回合不改插件源码，避免未获同意就走发布 |

## 5 修复与被否方案

见 PC-021 §3。否决过「只加兜底、不改冲突检测」：页面会停在说明文字，插件声明路径进不去。

## 6 重构提案与结论

R0。默认标签仍是手写种子，没有改成从清单菜单名生成。理由：清单失败时壳仍要有标签，生成逻辑要动导航时序，超出这次把页面打开的范围。

## 7 守卫落地

`tabs.test.ts` 断言种子标签为「智能体」。`dynamicPlugins.test.ts` 断言带兜底路由时 `/ai-agent` 仍注册在声明路径。
