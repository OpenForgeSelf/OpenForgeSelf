# AI-Native Engineering 闭环文档模板

> 配套规范：`docs/04-standards/ai-native-engineering-workflow.md`（强制）｜群 SOP：`ai-native-engineering-loop`
> 产物落点：`docs/ai/pilot/<task-id>/`（每任务一目录；文件去掉 `.tpl` 后缀：`00-repository-understanding.md` ~ `06-review.md`，最终汇报直接用 `07-final-report.tpl.md` 结构发群消息）

| 模板 | 阶段 | 产出文件 |
| --- | --- | --- |
| `00-repository-understanding.tpl.md` | Stage 0 理解仓库 | 00-repository-understanding.md |
| `01-intent.tpl.md` | Stage 1 意图 | 01-intent.md |
| `02-spec.tpl.md` | Stage 2 规格 | 02-spec.md |
| `03-plan.tpl.md` | Stage 3 计划 | 03-plan.md |
| `04-task.tpl.md` | Stage 4 Agent 工作单元 | 04-task.md |
| `05-evidence.tpl.md` | Stage 7 证据 | 05-evidence.md |
| `06-review.tpl.md` | Stage 8 审查 | 06-review.md |
| `07-final-report.tpl.md` | 最终汇报 | 群消息正文（铁律6） |
