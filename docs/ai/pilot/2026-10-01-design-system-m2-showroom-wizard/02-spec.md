## Input

- `preview-css`：`{brief?,seedColor?,hue?,chroma?,density?,typeRatio?,typeBasePx?,radiusBase?,motionScale?,brandName?,industry?,accentHueOffset?,theme?}`；`theme` 缺省 `light`；`themes` 若被传入会被忽略。
- 界面输入：向导四步字段、微调四控件、交付页的代码文本（≤200KB）与语言。
- 哈希：`#/showroom/dashboard?outfit=preset:admin-calm&theme=dark&device=desktop`。

## Output

- `preview-css` → `{success:true,data:{theme,css,seed,industry,hue,notes}}`（沿用控制器 `Data(...)` 信封）；`css` 与 `export?format=css` 同形（`:root{…}` + reduced-motion + 焦点环），去掉 `/* */` 注释后逐字相同。
- 界面输出：见 FR2–FR16；所有展示的颜色/字体/尺度值要么是后端 CSS 文本里的字面值，要么是 `var(--ds-*)` 引用，前端不换算。

## Business Rules

1. **展厅不写库**：唯一写入口是「保存为新设计」（走 M1 `quick-create`）与向导的「创建」（同端点）。试穿/微调/对比期间 12 张表行数不得变化（AC 钉）。
2. **同源**：画布上的任何设计值都来自后端文本（`export?format=css` 或 `preview-css`）；前端只做**文本级**操作（收窄作用域、按变量名取子集、按顺序拼接）。`pickVars` 保留的每条声明必须在原 CSS 里逐字存在（不改值、不新造）。
3. **模特零字面量 + 变量契约**：模特源码里 `var(--ds-*)` 的变量名集合 ⊆ **每个预设**（8 个）× 明/暗主题导出 CSS 所定义的变量集（后端契约测试读 `web/src/showroom/**` 源码核对，缺一个就红）。
4. **序号守卫与限流**：任何"await 后写共享 ref"都带序号守卫；缩略图取数并发 ≤3；微调防抖 250ms。
5. **能力降级必须显式**：`supports('presets' | 'quick-create' | 'preview-css' | 'agent' | 'review' | 'brief')` 缺哪项，对应入口置灰并写明原因（"后端未声明能力 x"），不装作没看见。
6. **大白话默认**：新模式默认大白话，「专业术语」开关一键切回；开关状态持久化。工作台文案不受词典影响。
7. **错误透明**：任何失败展示后端原文（状态码 + 消息），不替换成"出错了"；成功后一律回读自证（向导创建后 `GET projects/{id}` 核对令牌数）。
8. **只写不删**：界面不提供删除；归档沿用工作台既有按钮。
9. **14 个专业 section 不改**（含文案与类名）；e2e 对它们的断言一条不弱化。

## Boundary Conditions

- 没有项目：默认进 `start`；展厅衣柜只有预设；交付页提示"先创建或选择一个设计系统"。
- 项目存在但 `tokenCount==0`：不进衣柜，衣柜底部提示"有 n 个项目还没生成，去工作台生成或用向导重建"。
- M1 能力缺失（`presets/quick-create` 未声明）：向导与衣柜预设区整体置灰并说明；工作台不受影响。
- `preview-css` 失败（400/500）：缩略图显示错误态（不是空白）；舞台用 `PanelState` 展示后端原文；序号守卫保证旧响应不会覆盖新状态。
- `theme` 不在可用主题内（如预设没有 `high-contrast` 变体）：回落 `light` 并在舞台角标提示。
- 剪贴板不可用（非安全上下文/权限拒绝）：回退为**选中文本**并提示"请按 Ctrl+C"，不假装已复制。
- 窄屏（<1100px）：三栏纵向堆叠（衣柜在上、舞台居中、微调在下）；设备框超宽时舞台横向滚动，不撑破页面（`documentElement.scrollWidth - clientWidth ≤ 2`）。
- 网关未运行（`isRunning=false`）：「AI 接入」卡显示"网关未运行，去 MCP 中心启动"，片段仍给出但标灰。
- 衣柜里项目很多：最多显示最近更新的 12 个 + 「更多（n）」折叠。

## Error Handling

| 情形                            | 行为                                                                         |
| ------------------------------- | ---------------------------------------------------------------------------- |
| `quick-create` 409（code 冲突） | 向导停在第 4 步，`role="alert"` 展示后端原文，展开「高级」并聚焦 code 输入框 |
| `quick-create` 失败（生成阶段） | 展示后端原文（M1 已软归档半成品并回 code）；不显示成功页                     |
| `preview-css` 400               | 缩略图/舞台错误态 + 原文；微调面板不清空用户输入                             |
| 401/403                         | 沿用 `unauthorized` 空态（`PanelState state="unauthorized"`）                |
| `agent-access` PUT 失败         | 开关回滚到服务端真值并展示原文                                               |
| 试审查输入 >200KB               | 客户端拦截并提示"上限 200KB，请分批"，不发请求                               |
| SQLITE BUSY（读）               | 沿用 `http.ts` 的只读退避重试；写绝不重试                                    |

## Compatibility

- **REST**：纯增量（`preview-css`）；既有端点与响应形状不变；M1 端点按其契约消费。
- **前端**：14 个 section 组件与 DOM 不变；`window.prompt` 仅 UI 行为变化；`plugin.json` frontend 四项契约（route/views/entry/menu）不变。
- **e2e**：`nav()` 与全部既有断言不动；**新增** `enterWorkbench(page)` 助手（先进「工作台」，幂等），在页面刚加载（14 入口可见性断言之前）与 `page.reload()` 之后各调用一次；新增独立 spec，不往既有巨型用例里塞。
- **数据库**：零表变更；**版本**：2.8.0 → 3.0.0（`ModelVersion/GeneratorVersion/ProjectionVersion` 与 `plugin.json.Version` 同步；`DesignSystemAuthTests` 断言）。
- **宿主 / McpCenter**：不改。

## Non-functional Requirements

- **性能**：`preview-css` 单次 p95 < 400ms（开发机实测写入 Evidence）；展厅首屏 8 个预设缩略图在并发 ≤3 下完成，期间页面可交互；`pnpm run build` 产物体积增量记录入 Evidence（不设硬阈值，写出前后数字）。
- **可维护**：新逻辑拆成可纯函数/状态机测试的模块（`wizard.ts / outfits.ts / tune.ts / route.ts / glossary.ts / skin.ts / snippets.ts`），SFC 只做渲染与事件转发。
- **安全**：不渲染令牌明文；片段里令牌用占位符；`v-html` 不用于用户/后端文本（代码审查与 CSS 文本一律文本节点或 `<style>` 文本插值，`outfitId` 白名单字符）。
- **零 mock**：e2e 直连真实宿主；vitest 里 mock 仅限 `api`（沿用 `state.test.ts` 做法）。
- **无警告**：`pnpm run check` 0 error；新增 Vue 模板不写 filter/map 回调（隐式 any）。
