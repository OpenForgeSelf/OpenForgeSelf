## 4. 目标与非目标

**目标**
- G1：旧 composer 的**能力**一个不少地回到新组件（项目 / 工具 / 技能 / Agent / 模型 + chips 所见即所发）；
- G2：新增 `/` 命令面板（全部混合，分组 + 搜索 + 键盘可达）；
- G3：新增 `@` 文件提及（引用项目内文件）；
- G4：组件保持「可独立交付」—— 新能力全是 config 注入、默认关闭。

**非目标**
- 不做附件上传（组件源 ROADMAP 待定，需宿主后端契约）；
- 不新建「项目」实体（复用 `IProjectRegistryService`）；
- 不动消息渲染（步骤卡 / 工具卡属既有 TODO 缺口 1/2，另开任务）；
- 不改后端发消息契约（工具/技能/Agent 本就会随消息带上）。
