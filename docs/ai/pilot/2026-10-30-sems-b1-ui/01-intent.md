# Intent

> 阶段：Stage 1｜Task ID：2026-10-30-sems-b1-ui｜日期：2026-10-30

## Problem

Sems 1.2.0 已能用 HTTP 与工具创建规格、追加版本、关联 commit/PR/Issue、登记用例并查看覆盖，但 `Plugins/Sems/web` 只有项目、命令和运行，用户在页面上看不到这些能力。

## Why

用户要求先完善 Sems，测试通过后再把界面做出来。规格层后端已经有测试，缺的是同一插件页上的入口。

## Expected Outcome

在现有 `/sems` 项目卡片中可以完成：列出最新规格、创建、按版本号读取、追加版本、关联、反查、登记用例、查看覆盖。空、加载失败、无验收标准都有可见文案。

## Constraints

不新增后端端点，不改鉴权，不铺 B2–B14，不做沙箱。不新增菜单。不发布，不停用户宿主。不把「已登记」写成「已通过」。不提供「改旧版」或「列出全部历史版本」，因为后端没有这两个接口。

## Success Criteria

插件前端 `pnpm test` 与 `pnpm build` 通过。一条插件 e2e 走通创建、关联、登记、反查，并与规格 HTTP 对账。源码走查能在 dev-stack 上点开同一条链路。发布与 `:51888` 复验不在本任务完成条件里。
