# Intent

> 阶段：Stage 1｜只描述「为什么做 / 做什么 / 做到什么程度」，**不提前决定具体代码实现**。
> Task ID：`2026-11-06-db-admin-query-tabs` ｜ 日期：2026-11-06

## Problem

DbAdmin 插件右侧只有一个查询工作区：编辑器草稿按**连接**保存，结果集/分页是**全局单份**。
在同一个连接里依次查询表 A、表 B 时，表 A 的 SQL 与结果会被表 B 覆盖（`DbAdminView.vue:50-55/353`），
用户无法对照两张表的结果，也无法保留手改过的 SQL。

## Why

数据库工作台的常见动线是"多表对照 / 多段 SQL 并排"。当前单实例模型让每次切换都成为破坏性操作：
用户必须记住/抄下上一条 SQL，且结果一换表就消失。这是用户明确点名的可用性缺陷。

## Expected Outcome

- 点开一张表即得到**独立的查询标签**：自己的 SQL、结果集、分页、错误态。
- 重复点同一张表 → **聚焦已打开标签**，不新建、不重置内容。
- 在标签间切换不丢任何一方的编辑器内容与结果（可来回切换）。
- 关闭标签、关闭连接、刷新页面（草稿恢复）都有确定行为，不出现"幽灵标签"。
- **选中即只执行选中部分**（用户补充需求）：编辑器里有选区时点「执行」只跑选区内的语句；
  无选区跑全文。按钮文案随选区变化（「执行选中」），避免误跑整段。
- **多语句批量执行 + 结果分页签**（用户补充需求）：一条查询标签内可写多条以 `;` 分隔的语句，
  点一次执行按顺序逐条跑，每条结果各占一个**结果标签**（结果 1/结果 2…），每标签独立分页；
  任一条失败即停止后续并标注未执行原因；写语句按既有审批流逐条审批。
  后端 `POST /query` 明确硬拒多语句（`SqlGuard.cs:92`），故由**前端按服务端同规则切分后逐条发送**，不改后端契约。
- **一个连接服务多张表**（用户补充需求）：连接可**可选**配置「默认表」——
  点了带默认表的连接就直接打开该表查询标签；未配置默认表的连接，点击只展开并加载全部表，
  由用户在树里自行点表开标签。避免"一张表建一个连接"。
  该默认表是**本机界面偏好**（落 localStorage），不进后端连接记录、不改 DB 结构。
- **按竞品一次补齐常规能力**（用户补充需求）：对标 DBeaver/Navicat/TablePlus/HeidiSQL 的 SQL 工作台常规能力，
  本批补：表名过滤 + 刷新、结果复制（整行）/CSV 导出、单元格详情、结果状态栏、快捷键统一；
  高亮/补全/格式化/事务/取消/排序过滤/内联编辑等大特性**明确不纳入**（理由与后续条件见 02-spec 对标节，落 NOT-to-do）。
  全程**不新增第三方依赖**、不改后端契约。

## Constraints

- 只改插件前端（`Plugins/DbAdmin/web/src/`）+ 宿主侧的 story/CT/e2e/文档；**不改后端契约、不改 DB 结构**。
- 不新增第三方依赖；样式只用 `--el-*` token + scoped CSS（`design:check` 会拦裸色值）。
- 不破坏既有能力：审批流、破坏性二次确认、审计、历史、Agent 回显、401 态、S-R 刷新恢复。
- localStorage 恢复快照 ≤64KB，且必须兼容旧版本快照（升级后首次打开不应丢草稿）。
- 插件前端不 `import` 宿主模块；产物契约不变（`web/dist/index.js` 导出名 = `plugin.json` `views[0]`）。
- 闸门1 未批准前不改业务文件（`AGENTS.md` §11）。

## Success Criteria

1. 同一连接依次点开两张不同表 → 出现两个标签，各自保留 SQL 与结果；来回切换内容不丢。
2. 再次点已开标签的表 → 标签数不变，聚焦原标签，用户改过的 SQL/已有结果**不被重置**。
3. 标签可关闭；关闭当前标签后聚焦相邻标签；关闭最后一个标签显示空态引导；删除连接时其标签一并关闭。
4. 执行/审批结果回到**发起该请求的标签**，不会因切到别的标签而写错位置。
5. 刷新页面后标签（连接/表/SQL）与当前标签从 localStorage 恢复，结果集不恢复且有提示文案。
6. 连接表单可填「默认表」：填了 → 点该连接即打开该表标签；留空 → 点连接只展开并加载全部表，不自动建标签。
7. 有选区时点执行只发送选中语句；无选区发送全文；两条语句执行后出现「结果 1 / 结果 2」两个结果标签，各自结果与分页互不干扰。
8. 门禁全绿：插件 `pnpm run build`、插件单测、宿主 `check`/`test`/`design:check`、DbAdmin CT、
   `e2e/plugins/db-admin` 冒烟主链路（含多标签/默认表/选中执行/多语句/过滤/导出断言）；亮/暗两态活动标签对比度 ≥4.5:1 实测。
9. 对标补齐的 5 项（表过滤刷新、复制/CSV 导出、单元格详情、结果状态栏、快捷键）在真实宿主可用，且不引入新依赖。
