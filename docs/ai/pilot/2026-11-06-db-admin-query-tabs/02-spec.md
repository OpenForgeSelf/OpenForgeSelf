# Specification

> 阶段：Stage 2｜必须从真实 Repository Understanding 与 Intent 推导。
> 规则：① 所有内容与实际项目一致；② 不得发明不存在的接口、类、模块；③ 不确定点显式记录为 `Unknown`。
> Task ID：`2026-11-06-db-admin-query-tabs`

## Functional Requirements

- FR-1 查询工作区改为**多标签**：每个标签持有独立的 `connectionId`、可选 `table`、`sql`、`result`、`resultError`、`page`、`pageSize`、`lastSql`、`running`。
- FR-2 打开表的查询标签：表节点**单击**（点行名）→ 打开/聚焦该表标签，编辑器预填 `SELECT * FROM <表名>`，同时展开该表列；
  点行首 `▸/▾` 只展开/收起列、不建标签。
- FR-3 去重聚焦：同一 `(connectionId, table)` 只允许一个表标签；重复触发只激活已有标签，**不重置 SQL、不清结果**。
- FR-4 自由查询标签：提供「+ 新建查询」，绑定最近一次点击的连接（`lastConnectionId`）；无连接时禁用并常驻显示原因。
- FR-5 标签切换：编辑器、结果格、分页、错误条、执行按钮状态全部随活动标签切换；非活动标签的状态在内存中保留。
- FR-6 关闭标签：`×` 关闭；关闭活动标签后激活右侧邻居，无右侧则左侧；关闭最后一个标签进入空态。
- FR-7 **连接默认表（用户补充需求）**：连接表单（新建/编辑）增可选「默认表」输入；保存后成为本机界面偏好。
  - 填了默认表：点击该连接 → 展开并加载表 + **直接打开/聚焦该表标签**。
  - 留空：点击该连接 → 只展开并加载全部表（不建标签），由用户点表开标签。
  - 默认表只落 localStorage 快照，**不进后端请求体、不改 DB 结构**；表名写错不阻塞（执行时按普通 SQL 错误显示在该标签）。
- FR-8 连接联动：点击连接节点 → 展开/收起；删除连接 → 关闭该连接全部标签并清掉其默认表偏好。
- FR-9 执行与分页作用域：执行/翻页只作用于**发起时的标签**；完成后即使已切走，结果也写回该标签（不覆盖当前标签）。
- FR-10 审批回填作用域：审批（含 Agent 发起的待审批）批准/拒绝后，结果写回**发起该请求的标签**；发起标签已被关闭时写回当前活动标签。
- FR-11 上限：最多 12 个标签；超限不新建，banner 提示「最多 12 个查询标签，请先关闭不用的标签」。
- FR-12 刷新恢复：localStorage 快照记录标签元数据（key/connectionId/table）+ 每个标签的 SQL + 当前活动标签 + 各连接默认表；结果集不恢复。
- FR-13 历史「放回编辑器」：同连接 → 填入当前活动标签的编辑器；异连接 → 新建一个该连接的自由查询标签并填入。
- FR-14 **选中执行**：编辑器存在非空选区时，点执行只发送选区文本；无选区发送全文。
  执行按钮文案随状态切换（「执行」/「执行选中」），并在选区时显示选中字符数。
- FR-15 **多语句切分**：前端按与后端 `SqlGuard` 一致的规则把执行文本切成多条语句
  （顶层 `;` 切分；跳过字符串、引号标识符、行注释、块注释、美元引号；`CREATE … TRIGGER` 的 `BEGIN…END` 块内不切）。
  未闭合引号/注释 → 客户端红条且**不发任何请求**。
- FR-16 **逐条执行 + 结果标签**：一词执行按语句顺序逐条发 `POST /query`（后端硬拒多语句，`SqlGuard.cs:92`），
  每条结果生成一个结果标签（「结果 1…N」），标签内保留该语句的 status/rows/total/elapsedMs/错误；
  单语句时不显示结果标签条（保持既有单结果体验）。
- FR-17 **失败即停**：任一条 rejected/error → 该结果标签红条，后续结果标签标记「未执行（第 N 条失败）」并停止发送。
- FR-18 **批量审批**：批量中某条 `awaiting_approval` → 暂停队列并弹出审批；批准后应用结果并继续后续语句；
  拒绝 → 该条标拒绝、其余标未执行。审批仍按既有破坏性二次确认规则。
- FR-19 **结果标签独立分页**：每个结果标签各自 `page/pageSize`；翻页只重发该标签对应的单条语句。
- FR-20 **表搜索与刷新**：schema 树加表名过滤框（大小写不敏感、只过滤已加载的表、不触发请求，无匹配显示「无匹配表」）；
  提供「刷新表」按钮，复用现有 force 重拉 + 竞态序号。
- FR-21 **结果复制与导出**：单元格双击复制（NULL 复制为 `NULL`）、当前行「复制整行」（制表符分隔）；
  当前结果标签导出 CSV（表头 = 列名，仅**当前页**，文件名标注页码）。
- FR-22 **单元格详情**：双击长文本/对象值弹出详情浮层，显示完整内容并支持复制（空值/超长行可滚动）。
- FR-23 **结果状态栏**：每个结果标签显示「N 行 · X ms」（取 `total` 与 `elapsedMs`，无则只显示行数）。
- FR-24 **快捷键统一**：`Ctrl+Enter` 与 `F5` 均走同一执行入口（选区优先），执行按钮 tooltip 标出快捷键。

## Input

- schema 树表节点单击行名（开标签）/ 单击 `▸/▾`（仅展开列）、连接节点点击。
- 连接表单「默认表」输入（可选）。
- 顶部标签条点击、关闭按钮、「+ 新建查询」。
- 编辑器输入（每标签独立 v-model）、`Ctrl+Enter` 执行、**编辑器选区**（textarea `selectionStart/End`）、分页控件。
- 多语句输入（单条查询标签内以 `;` 分隔多条）。
- 既有数据源：`GET /providers`、`GET /connections`、`GET /connections/{id}/tables`、`GET /connections/{id}/tables/{table}`、
  `POST /query`、审批与历史端点（均不新增/不改契约）。

## Output

- 标签条 DOM：`data-testid="query-tabs"`，单标签 `data-testid="query-tab-<key>"`、关闭 `data-testid="tab-close-<key>"`、
  运行中标记 `data-testid="tab-running-<key>"`、新建 `data-testid="tab-new"`。
- 每标签编辑器沿用 `data-testid="sql-editor"`（活动标签唯一渲染）；结果格沿用 `result-grid` / `pager`。
- 结果标签条：`data-testid="result-tabs"`，单标签 `data-testid="result-tab-<index>"`；活动结果格沿用 `result-grid` / `pager`；
  未执行态 `data-testid="result-skipped-<index>"`。
- 执行按钮 `data-testid="run"`，文案「执行」/「执行选中（N 字符）」。
- 空态：`data-testid="workspace-empty"`。
- 恢复提示文案改为标签口径：`已从上次会话恢复：N 个连接 · M 个查询标签（结果集与密码不恢复；待审批已从服务端重拉）`。

## Business Rules

- BR-1 标签 key：表标签 `t:<connectionId>:<table>`；自由标签 `m:<connectionId>:<seq>`（seq 单调递增，不与已存在 key 冲突）。
- BR-2 表标签的默认 SQL 只在**创建时**写入一次；之后任何聚焦/切换都不得覆盖用户编辑或重置结果。
- BR-3 结果集、错误态、分页只在内存（与现状一致），不落 localStorage。
- BR-4 标签条顺序 = 创建顺序；激活只改变活动 key，不重排。
- BR-5 表标签标题 = 表名原文（沿用 2026-11-06 输入3 的「不加『表』字」决定）；自由标签 = 「新查询」；`title` 属性给「连接名 · 表名」以便同名表区分。
- BR-6 同一连接内不同表、不同连接同名表都必须各自独立成标签。
- BR-7 执行请求序号按标签独立：关闭标签后迟到的响应必须丢弃（避免写进已关闭/别的标签）。
- BR-8 旧快照迁移：`version:1` 的 `drafts: Record<connectionId, string>` 视为每个连接一个自由标签（`m:<connectionId>:0`），
  `activeConnectionId` 映射为对应标签的激活。
- BR-9 默认表按 `connectionId` 存于 localStorage 快照 `defaultTables`；值 `trim()` 后为空 = 未配置；
  **绝不进入 `POST/PUT /connections` 请求体**（保存连接时只提交后端既有字段）。
- BR-10 点击带默认表的连接：先展开并触发加载表，再按表标签规则打开/聚焦（与手动点表共用同一 key，天然去重）。
- BR-11 `lastConnectionId` = 最近一次点击的连接或活动标签所属连接；用于「+ 新建查询」，不产生额外标签。
- BR-12 选区：执行时读编辑器 `selectionStart/End`；`trim()` 后非空即以选区为执行文本，否则用全文。
  按钮在选区存在时显示「执行选中（N 字符）」；`Ctrl+Enter` 同规则。
- BR-13 切分规则镜像后端 `SqlGuard.Strip/SplitStatements`：顶层 `;` 切分；跳过 `'…'`（含 `''` 与 `E'…'` 反斜杠转义）、`"…"`/`` `…` ``/`[…]`、
  `--` 行注释、`/* */` 块注释、`$tag$…$tag$`；`CREATE [TEMP] TRIGGER … BEGIN…END` 块内分号不切。
  未闭合引号/注释 → 抛客户端错误（红条，不发请求）。
- BR-14 仅空白/仅注释的片段丢弃；全无有效语句 → 红条「没有可执行的语句」，不发请求。
- BR-15 结果标签按语句创建顺序编号「结果 1…N」；**单语句不渲染结果标签条**（回归既有体验）。
- BR-16 每条语句**单独** `POST /query`（后端硬拒多语句）；服务端审计/历史因此逐条记录，属预期。
- BR-17 顺序执行，任一条失败即停止；后续结果标签状态 `skipped`，文案「未执行（第 N 条失败）」。
- BR-18 `awaiting_approval` 时批量队列暂停：记录 `{tabKey, statements, nextIndex}`；批准 → 继续，拒绝 → 其余标未执行。
  队列仅内存保存，刷新即丢弃（与"结果集不恢复"一致）。
- BR-19 分页仅重发该结果标签对应的单条语句，携带该结果标签自己的 `page/pageSize`；不影响其他结果标签。
- BR-20 关闭查询标签 → 其批量队列与结果标签一并丢弃；迟到的单条响应按标签存在性丢弃。
- BR-21 CSV 遵循 RFC 4180：含逗号/换行/双引号的字段用双引号包裹并双写引号；NULL 写 `NULL`（与界面一致）；
  UTF-8 **带 BOM**；文件名 `<表名或query>-r<结果序号>-p<页码>-<yyMMddHHmm>.csv`；只导出当前结果标签当前页。
- BR-22 复制走 `navigator.clipboard`；失败（非安全上下文/权限拒绝）→ banner 提示「复制失败，请手动选择文本」，不静默。
- BR-23 表过滤只作用于已加载的 `tables[connId]`；清空输入恢复全量；匹配字段为表名（大小写不敏感）。
- BR-24 刷新表复用 `loadTables(connId, force)` 的请求序号，旧响应不得覆盖新结果。

## Boundary Conditions

- 无连接：不创建标签，工作区显示空态引导「先新建/选择连接」。
- 无标签：编辑器、执行栏、结果格不渲染，显示空态「在左侧选择一张表开始查询」+「+ 新建查询」。
- 表在打开后被删除：标签保留，执行时报 `sql_error` 红条在该标签内。
- 标签数达上限（12）：见 FR-11。
- 快照超 64KB：先丢非活动标签的 SQL（按长度从大到小），再截断活动标签 SQL 尾部；连接列表最后裁剪（沿用 `fitToBudget` 思路）。
- 多语句：仅空白/仅注释片段丢弃；全部片段为空 → 红条；选区截断导致语句不完整 → 按普通 SQL 错误显示在该结果标签。
- 结果标签数量 = 请求语句数；关闭查询标签即整体丢弃；不做"只关某个结果标签"的独立关闭。
- 单条语句分页期间切换查询标签：响应仍回原结果标签（同 BR-7）。
- 窄屏：标签条横向滚动，活动标签 `scrollIntoView`；标题 ellipsis + `title`。

## Error Handling

- 查询失败/硬拒/驱动缺失：红条留在**该结果标签**，切走再切回仍在；不弹全局横幅覆盖。
- 客户端切分失败（未闭合引号/注释）：红条写在该查询标签的结果区，**不发任何请求**。
- 批量中某条失败：该结果标签红条，后续标「未执行（第 N 条失败）」，不继续发送。
- 401：沿用全局未授权横幅，整个工作区不渲染（含标签条）。
- 恢复失败（快照损坏/超限）：静默丢弃并正常空态（沿用 `loadSnapshot` 行为）。
- 关闭标签时该标签正在执行：丢弃其响应（BR-7），不发取消请求（后端契约不变）。

## Compatibility

- 现有 API 契约零改动；后端、`plugin.json` 路由不变。
- **多语句在 UI 层放开、API 层仍硬拒**：由前端逐条发送；这是交互层语义，服务端审计/历史逐条记录（预期行为，非缺陷）。
- CT fixture 向后兼容：未提供 `tabs` 时按 `activeConnectionId + sql` 生成单个自由标签（现有 26 个 story 不改即通过）。
- 旧 localStorage 快照按 BR-8 迁移。
- 既有 `selectConnection` 清结果的行为被"标签化"取代：点击连接不再清空任何标签内容。

## Non-functional Requirements

- 切换标签 ≤100ms 内完成（纯内存切换，不发请求）。
- 标签切换后活动标签 `scrollIntoView`，不产生整页滚动。
- 结果行数大时切换标签不得重新渲染所有非活动标签（`v-if` 只渲染活动标签内容）。
- 单测覆盖纯逻辑模块；CT 覆盖多标签渲染态；e2e 覆盖真实链路。

| 结果内联编辑 | TablePlus「Inline edit」 | 与审批/破坏性确认模型冲突，且写路径需专门设计；属独立大特性 |
| 结果图表 | DBeaver Charts | 需图表依赖；非查询工作台核心 |
| 标签拖拽排序/重命名 | DBeaver/DataGrip | 交互增强，非缺失能力；记 TODO 候选 |
| 执行错误定位到编辑器行号 | DBeaver error indication | 后端只回错误消息、无偏移；需契约扩展 |
| 连接 SSH/SSL/用户管理 | HeidiSQL | 与本插件"本地自用"定位不符，且属连接层大特性 |
| 数据导入/导出整库 dump | HeidiSQL/TablePlus | 需后端流式端点；本插件定位是查询工作台 |

| 重复打开同表 | 同上，表已有标签 | 仅激活已有标签；SQL 与结果原样保留 | 已存在 | 标签高亮 | — | 不得重置/清空 |
| 切换标签 | 点击标签 | 编辑器/结果/分页/错误条换成该标签的内容 | 活动 / 非活动 | 高亮 + 底部主色指示线 | — | 执行中切走不打断，结果仍回原标签 |
| 选中后执行 | 编辑器拖选文本 + 点「执行选中」/`Ctrl+Enter` | 只发送选区语句；结果标签只含选中语句 | 有选区 / 无选区 | 按钮文案变「执行选中（N 字符）」；选区消失后恢复「执行」 | — | 选区仅空白 → 回到全文；选区未闭合引号 → 红条不发请求 |
| 多语句执行 | 编辑器含多条 `;` 分隔语句，点执行 | 结果区出现「结果 1…N」标签条，逐条填充；默认激活结果 1 | 单语句 / 多语句 / 有失败 | 每条状态点（成功/失败/待审批/未执行） | 无有效语句 → 红条「没有可执行的语句」 | 失败即停，后续标「未执行」 |
| 切换结果标签 | 点击「结果 i」 | 结果格/分页换成该条语句结果 | 活动 / 非活动 | 高亮 | 写语句无行 → 「影响 N 行」 | 不重新执行、不改变其他结果 |
| 结果分页 | 点分页 | 只重发该结果标签对应的单条语句 | — | 局部 loading | — | 页码按该结果独立 |
| 批量审批 | 多语句中含写语句 | 执行到该条暂停并弹审批；批准后继续后续语句 | 待审批 / 已批准 / 拒绝 | 审批浮层 + 该结果标签状态 | — | 拒绝 → 其余标未执行 |
| 新建自由查询 | 点「+ 新建查询」 | 新增「新查询」标签并激活，编辑器为空 | 活动 / 非活动 | 标签出现 | 编辑器占位「输入 SQL，Ctrl+Enter 执行」 | 无连接 → 按钮禁用 + 常驻原因；达上限 → banner |
| 关闭标签 | 点标签 `×` | 关闭该标签；若为活动标签则激活右邻（无则左邻） | 有标签 / 最后一标签 | 相邻标签激活 | 最后一个关闭 → 工作区空态 | 关闭执行中的标签 → 丢弃响应 |
| 填写默认表 | 连接表单输入 + 保存 | 该连接记住默认表（仅本机）；连接节点 `title` 提示「默认表：X」 | 有 / 无 | 保存成功后生效 | 留空 = 未配置 | 不进入后端请求体 |
| 点击连接（有默认表） | 点击连接节点 | 展开并加载表，同时打开/聚焦该默认表标签 | 展开 / 收起 | 标签激活；树展开 | — | 收起状态点击只展开不建标签（再点收起仅收起） |
| 点击连接（无默认表） | 点击连接节点 | 只展开并加载全部表，不新建标签 | 展开 / 收起 | 局部「加载表…」 | 无表 → 「（无表）」 | 不改动既有标签内容 |
| 删除连接 | 确认删除 | 该连接全部标签关闭 + 默认表偏好清除；若全部关闭 → 空态 | — | 既有删除确认弹窗 | — | 只删配置不删库文件（现状不变） |
| 历史回填 | 历史行「↺」 | 同连接 → 填入当前标签；异连接 → 新建自由标签并填入 | — | 标签/编辑器内容变化 | — | 不改动已有标签的其他状态 |
| 审批回填 | 批准/拒绝 | 结果写回发起标签；发起标签已关闭则写回当前活动标签 | 有发起标签 / 无 | 该标签结果区更新 | — | 不得写入非发起标签 |
| 表搜索 | 在 schema 过滤框输入 | 只显示名称匹配的表；清空恢复全量 | 有输入 / 无输入 | 即时过滤（本地，无请求） | 无匹配 → 「无匹配表」 | 展开状态保留 |
| 刷新表 | 点连接行「刷新」 | 重新拉取该连接表列表 | 加载中 / 完成 | 局部 loading；旧响应丢弃 | 无表 → 「（无表）」 | 不清空已展开列 |
| 复制单元格 | 双击单元格 → 详情浮层「复制」 | 复制原文到剪贴板（NULL → `NULL`） | 成功 / 失败 | 成功 toast「已复制」；失败 banner | — | 只读，不影响结果 |
| 复制整行 | 工具条「复制整行」 | 复制当前选中行（制表符分隔） | 有选中行 / 无 | 成功 toast；无选中时按钮禁用 | — | 不写回任何数据 |
| 查看单元格详情 | 双击单元格 | 弹出详情浮层显示完整值 | 打开 / 关闭 | 浮层 + 复制按钮 | 空值 → `NULL` | Esc / 点遮罩关闭 |
| 导出 CSV | 点结果区「导出 CSV」 | 下载当前结果标签当前页 CSV | 有结果 / 无结果 | 按钮禁用 + 原因（无结果）；成功无弹窗 | — | 仅当前页，文件名含页码 |

### 视觉规格（目标态）

- **标签条几何**：位于连接信息条（`conn-bar`）之下、编辑器之上；高 34px；左缘与 `conn-bar` 文本左缘对齐；
  标签间距 4px；横向滚动，不换行；右端固定「+ 新建查询」按钮（不随滚动消失）。
- **活动标签**：底色 `--el-color-primary-light-9`，文字 `--el-color-primary`，底部 2px `--el-color-primary` 指示线；
  非活动：透明底 + `--el-text-color-secondary` 文字。关闭 `×` 12px，非活动/悬停时可见（`--el-text-color-secondary`，悬停 `--el-color-danger`）。
- **长标题**：单行 `max-width: 200px`，`text-overflow: ellipsis`，`title` 给「连接名 · 表名」。
- **连接表单「默认表」输入**：位于「名称」之后，label「默认表（可选）」，`data-testid="cf-default-table"`；
  下方常驻说明「仅本机记住；留空则点击连接只展开并加载全部表」；复用表单现有输入样式（不新增视觉表面）。
  provider 切换不清空已填默认表（用户可自行清空）。
- **连接节点提示**：配置了默认表的连接节点 `title="默认表：<表名>"`，不改节点主文案。
- **空态**：虚线边框区（`--el-border-color`，圆角 10px）+ 主文案 +「+ 新建查询」按钮；与左栏 `empty-guide` 风格一致。
- **结果标签条**：位于编辑器/执行栏之下、结果格之上；仅在语句数 >1 时渲染；高 28px；标签文字「结果 i」12px；
  活动：`--el-color-primary` 文字 + 1px `--el-color-primary` 下划线；非活动：`--el-text-color-secondary`；
  状态点 6px（成功 `--el-color-success`、失败 `--el-color-danger`、待审批 `--el-color-warning`、未执行 `--el-text-color-placeholder`），
  点旁置 `title` 文案（如「未执行（第 2 条失败）」）。
- **执行按钮选区态**：按钮文案「执行选中（N 字符）」时保持同一主按钮样式，不新增颜色；禁用原因仍常驻可见。
- **结果格与分页**：沿用既有 `result-grid` / `pager` 结构与 token，不新增表格样式。
- **表过滤框**：位于 schema 树顶部、与连接列表左缘对齐；高 28px；占位「筛选表名」；与既有输入 token 一致。
- **结果工具条**：结果标签条右端依次「复制整行」「导出 CSV」小按钮（`--el-text-color-secondary`，悬停主色）；
  状态栏「N 行 · X ms」右对齐 12px；无结果时导出按钮禁用并显示原因。
- **单元格详情浮层**：沿用现有浮层遮罩与卡片 token（与审批浮层同一视觉层级），内容区等宽字体、可滚动、右上「复制」。

### 交互验收标准（并入 Acceptance Criteria）

- 每个交互点至少一条可测断言（见下方 AC），断言锚在真实渲染 DOM / 真实请求返回。
- 空态分级：无连接 / 无标签两种文案不同且都可测。
- 异步：切换标签不发请求；执行中标签显示运行标记；重复点击执行去重（沿用 `running` 禁用）；关闭后迟到响应丢弃。
- 禁用态原因可见：沿用「执行」按钮旁常驻原因文案，按活动标签计算。
- 破坏性/状态变更：关闭标签不是破坏性操作（内容仅内存），无需二次确认；删除连接沿用既有确认弹窗。

### 走查符合性（DoD 绑定）

- 走查按 `ui-ux-design`「走查 UI 符合性清单」逐项核对：CRAP（活动标签层级、重复标签样式一致、左缘对齐、标签与编辑器亲密性）、
  长表名 ellipsis、窄屏横向滚动、亮/暗两态对比度实测。
- e2e 覆盖：开两个标签、切回不丢、重复开表不新增、关标签邻居激活、空态、活动标签对比度（light + 显式 `html.dark`）。

## Acceptance Criteria

- [ ] AC-1 **单击**表 A 行名 → 出现标签 A（编辑器预填 `SELECT * FROM A`，表 A 列同时展开）；再单击表 B → 标签数 2，A/B 编辑器 SQL 不互相覆盖。
- [ ] AC-2 A 产生结果后切到 B，再切回 A → A 的编辑器内容与结果格完整重现（B 的内容同时保留）。
- [ ] AC-3 再次打开已存在的表 A → 标签数仍为 2，A 被激活；用户改过的 A 的 SQL 与既有结果未被重置。
- [ ] AC-4 关闭活动标签 → 相邻标签被激活；连续关闭至 0 → `workspace-empty` 可见，无编辑器/结果格。
- [ ] AC-5 达 12 个标签再开新表 → 不新增标签，banner 出现「最多 12 个查询标签」。
- [ ] AC-6 删除连接 → 该连接标签全关 + 默认表偏好清除；其他连接标签不受影响。
- [ ] AC-7 刷新页面 → 标签顺序/连接/表/SQL/活动标签/各连接默认表恢复；恢复提示为标签口径；结果集不恢复。
- [ ] AC-8 标签 A 发起写 → 审批弹窗；切到标签 B 后点批准 → 结果呈现在标签 A（B 不被写入）。
- [ ] AC-9 标签 A 执行中切到 B，A 完成后结果仍写入 A；关闭 A 后其迟到响应被丢弃。
- [ ] AC-10 历史「↺」：同连接填入当前标签；异连接新建标签并填入 SQL。
- [ ] AC-11 活动标签对比度：`getComputedStyle` 实测 light 与显式 `html.dark` 两态正文对比度 ≥4.5:1（数值写入 05-evidence）。
- [ ] AC-12 **默认表**：连接表单填「默认表」并保存 → 点该连接即打开该表标签且加载表；留空 → 点连接只展开并加载全部表，标签数不变；
  `POST/PUT /connections` 请求体不含该字段（单测断言）；刷新后默认表仍生效。
- [ ] AC-13 点表行首 `▸/▾` → 只展开/收起列，不新增标签、不改变活动标签。
- [ ] AC-14 **选中执行**：编辑器写两条不同列的 SELECT，选第二条后点执行 → 只发该条（结果列/行只对应第二条；断网抓请求断言 1 条）。
- [ ] AC-15 **多语句**：两条 SELECT 全选执行 → 出现「结果 1 / 结果 2」标签，各自结果正确；切换结果标签不重跑、不串数据。
- [ ] AC-16 **失败即停**：第二条为语法错误 → 结果 2 红条，结果 3（若有）显示「未执行（第 2 条失败）」且未发请求。
- [ ] AC-17 **批量审批**：两条语句，第二条为写 → 执行到第二条弹审批；批准 → 第二条结果产出且批量结束；拒绝 → 第二条标拒绝、后续未执行。
- [ ] AC-18 **结果分页**：多语句下每个结果标签独立翻页，页码互不影响。
- [ ] AC-19 **单语句回归**：只执行一条语句时不出现结果标签条，结果格/分页与改动前一致。
- [ ] AC-20 **切分正确性**（单测）：字符串/注释/引号标识符里的 `;` 不切；`CREATE TRIGGER … BEGIN…END` 不切；未闭合引号报错不发请求。
- [ ] AC-21 表过滤：输入子串只显示匹配表、清空恢复；无匹配显示「无匹配表」；过滤不发请求（网络条数不变）。
- [ ] AC-22 复制：双击单元格 → 详情浮层「复制」得到原文（NULL → `NULL`）；「复制整行」为制表符分隔；剪贴板拒绝时出现失败 banner。
- [ ] AC-23 导出 CSV：含表头；逗号/引号/换行字段正确转义；文件名含 `-p<page>`；UTF-8 BOM（单测 + 浏览器下载断言）。
- [ ] AC-24 状态栏与详情：结果标签显示「N 行 · X ms」；双击单元格弹出完整值浮层并可复制；Esc 关闭。
- [ ] AC-25 门禁：插件 `pnpm run build`、插件单测、宿主 `check`/`test`/`design:check`、DbAdmin CT、
  `e2e/plugins/db-admin` 冒烟主链路全绿；`docs/02-features/044-db-admin.md` 与 `ui-design-brief.md` 同步。

## Unknown

| 不确定点 | 影响 | 处理方式 |
| --- | --- | --- |
| 标签上限 12 是否合适 | 影响重度用户 | 默认 12，超限 banner 可调；如需更高可后续改常量 |
| 默认表是否要同步到后端（跨设备） | 影响实现面 | 本批**仅本机**（用户原话是"打开链接就是这个表"的功能诉求，未要求跨设备）；跨设备需 DB 迁移，属高风险另议 |
| 是否需要标签拖拽排序 | 影响交互复杂度 | 本批不做（记 TODO 候选，非用户诉求） |
| 多语句批量条数上限 | 影响安全/性能 | 本批不设硬上限（顺序发送天然限速）；如后续需要可加常量 |
| 是否需要「执行全部 + 执行选中」双按钮 | 影响按钮布局 | 默认单按钮随选区切换文案（用户原话"选择sql，点击执行只执行选择的语句"） |
