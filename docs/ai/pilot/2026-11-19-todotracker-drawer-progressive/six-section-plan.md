# 六段方案 · TodoTracker 抽屉与渐进披露

## 1. 目标

快速记待办不强迫填齐；编辑用右侧抽屉不挤列表；详情/编辑同壳、分类渐进披露。成功判据：创建仅标题；开抽屉后列表宽度不变；下发缺项点名；原型截图可审。

## 2. 改动

- `TodoView.vue`：去掉右侧分栏 → 全宽列表 + 抽屉壳  
- `TaskDetail.vue`：三页签改分类折叠；缺项下发反馈触发展开  
- 列表文案：「还缺」→「下发前待补齐」  
- e2e 选择器对齐抽屉；回写 `005-todo-tracker.md`  
- **本回合**：仅 Spec + HTML 原型 + 截图（不改业务代码）

## 3. 不改

## 4. 验证
