# Specification

## Functional Requirements

- AC1 跨会话仍待决定的智能体审批能一次列出，过期的不出现。
- AC2 要你处理、要续跑、在跑、知道即可、待触发分层。破坏性或剩余不足 2 分钟为紧急。
- AC3 同一条执行只出现一次。待办委派的外部任务留在外部 Agent 那一行，并可带来自待办。终端已有待批时不再另开在跑。智能体总览已代表的定时触发不再重复。
- AC4 在跑覆盖智能体、外部 Agent、终端、工程台、脚本、工作流、定时任务、文件扫描、已打开的浏览器。工程台按 pid 去重；对上项目进工程台，对不上进系统监控。
- AC5 一路 401 只标这一路需要访问密钥，404 标未启用，其余照常。
- AC6 知道即可最多 20 条，失败在前。
- AC7 点击带查询参数打开对应详情：脚本、工作流、定时任务、系统监控、数据库、待办、外部 Agent、工程台、文件扫描、终端。
- AC8 标签可见名是运行实况。阻塞条数大于 0 时标签显示数字，0 不显示。

## Input

各来源现成列表，加上本批补的只读列表：`GET /api/ai-agent/approvals/pending`、`GET /api/workflows/executions?status=Running`、`GET /api/scheduler/running`、`GET /api/filetools/folders/scans`、`GET /api/browser-use/session`。

## Output

运行实况页上的分层卡片，以及来源页按查询参数打开的详情。

## Business Rules

决定仍回各来源。外部 Agent 同意只放行这一次。终端待批只在本次宿主运行期间有效。重新扫描不启动、不停止进程，且不在打开页面或定时器里调用。

## Boundary Conditions

浏览器未打开不占一行。对不上项目的进程归入未归属。读取未完成时不显示 0 条。

## Error Handling

单路失败不挡住其余。决定失败把原因留在卡片上。

## Compatibility

`taskCenterApi.ts` 的旧三源映射保留，既有单测继续通过。工作流 `GetExecutionsAsync` 增加可选状态参数，旧调用不传时行为不变。

## Non-functional Requirements

15 秒拉取。不新增裸色值，不用胶囊按钮。不改 IM 进展。

## Interaction Design

| 交互点 | 触发 | 结果 | 状态 | 反馈 | 空态 | 边界 |
| --- | --- | --- | --- | --- | --- | --- |
| 打开页面 | 进入 `/task-center` | 先显示「正在读取」，完成后分层 | 读取中 / 已读 | 不先画 0 | 没有任何卡片时说明现在没有要处理的，也没有在跑的 | 某路失败只在该路提示 |
| 同意 | 点非破坏性审批的同意 | 卡片留下结果句，下次刷新离开 | 处理中禁用 | 不弹成功提示 | 无待批则不出现这一层 | 第一张紧急审批的同意为金色填充 |
| 拒绝 | 点拒绝 | 卡片留下「已拒绝」 | 处理中禁用 | 朱红文字按钮 | 同上 | 不批量同意 |
| 破坏性批准 | 点会破坏数据的同意 | 先确认；取消留在待批；批准后留结果句 | 确认中 | 批准按钮朱红实心 | 无 | 取消不发决定 |
| 继续 | 点要续跑的继续 | 走原续跑地址 | 处理中 | 结果留在卡片 | 没有卡住回合则不出现 | 该会话已有待批时不进这一层 |
| 在跑一行 | 点击 | 到来源页并带查询参数 | 可点 | 无 | 这一段为空则不出现 | 段内滚动，不截断 |
| 来自待办 | 点次链接 | `/todo?todoId=` | 可点 | 无 | 对不上待办则没有次链接 | 主点击仍是执行体 |
| 重新扫描 | 点击 | 查找已登记项目目录下的进程 | 扫描中按钮禁用 | 按钮旁写明不启动、不停止 | 没有新增进程则列表不变 | 不在定时器里调用 |
| 待触发 | 点立即运行 | 触发该定时任务 | 处理中 | 结果留在卡片 | 没有启用任务则不出现 | 正在跑的不重复出现在这一层 |
| 标签数字 | 拉取完成 | 只显示阻塞审批条数 | 有 / 无 | 数字在「运行实况」标签上 | 0 不显示 | 不把在跑算进去 |

视觉：沿用宿主 token。金色填充只用在第一张紧急同意。拒绝是朱红文字。破坏性确认是朱红实心。页面不放亮暗色切换。
