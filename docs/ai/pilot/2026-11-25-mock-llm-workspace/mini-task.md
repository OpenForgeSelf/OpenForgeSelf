# mini-task：mock 模型、真实计划与右侧面板

轻量任务。空库默认模型改为 mock，规则文件驱动文本和工具调用。计划模式必须由 submit_plan 交出真实步骤。右侧面板的记忆写回记忆库，设计确认写入设计系统，计划步骤显示为工作流。

## Intent

- 本地预览不再指向 localhost:1234。
- 智能体测试要能走工具调用和多轮，计划不能停在「准备 / 执行」回退草稿。
- 右侧面板要有可核对的内容：计划步骤、工具返回、记忆、设计项目。

## Spec

- 命中 mock 规则时，管道返回 Chat Completions SSE。同一步可以同时有正文和工具。
- 规划提示命中时调用 submit_plan，计划目标是「先列出项目根目录，再根据文件列表写总结」，步骤为「列出项目根目录」「根据列表写总结」。
- 确认执行后第一步调用 list_files，结果正文出现在工具行。第二步调用 complete_step。不得再出现「规划失败，已用回退计划」。
- 一轮结束后给出建议和待办。记忆写回调用记忆库。设计确认调用 design_create。

## Interaction Design

| 交互点 | 触发 | 结果 |
| --- | --- | --- |
| 计划任务 | 发送「请列一个两步计划：先看目录，再总结」 | 右栏出现两步真实计划，可确认或改计划 |
| 确认并执行 | 点击确认并执行 | 列出真实目录，写出总结，会话已完成 |
| 工具行 | 点击 list_files | 展开返回 JSON，能看到目录条目 |
| 记忆 | 写回 | 记忆库能搜到该条 |
| 设计 | 确认写入 | 设计系统出现草稿项目 |

空态、出错、无权限沿用现有会话和面板文案。无权限时页面仍是 401，不在本批改。
